# Snapkitty/woz-vault

## Resumen

El repositorio `Snapkitty/woz-vault` no contiene un modelo de inteligencia artificial, sino la descripción de un dispositivo de hardware denominado "WOZ VAULT", aparentemente un módulo de seguridad física para custodia de claves criptográficas. Según la model card, se trata de un "Hardware Key Vault" que almacena un par de claves Ed25519 generadas en una ceremonia de sellado, con registro de acceso de tipo WORM (write-once, read-many) y capacidad de borrado remoto. No se proporciona ningún artefacto de modelo, pesos, arquitectura ni pipeline de inferencia.

Dado que la ficha solicitada está pensada para modelos de IA, la siguiente información se limita a reflejar que este repositorio no es un modelo y que los datos técnicos habituales no están disponibles. No se debe interpretar como un modelo de lenguaje, visión u otro tipo de IA.
