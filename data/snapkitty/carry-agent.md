# Snapkitty/carry-agent

## Resumen

El repositorio `Snapkitty/carry-agent` aloja un proyecto denominado CARRY, descrito en su model card como el "gemelo adversario" de CARTO, un agente cartográfico. La documentación presenta un sistema de verificación formal y gobernanza basado en conceptos de topología de trenzas (braid group B₃), anyones de Fibonacci y un simulador cuántico. Sin embargo, el repositorio no contiene archivos de modelo (tamaño 0.0 GB) y no se proporciona información sobre arquitectura de red neuronal, parámetros, entrenamiento o capacidades de IA. La fecha de creación y actualización es el 3 de septiembre de 2026, aunque el contenido no ofrece datos técnicos verificables sobre un modelo de aprendizaje automático.

La model card describe un stack de software con capas formales (Lean 4, Agda), cuánticas (simulador de anyones), de gobernanza (DAG dual, BLAKE3) y de runtime (Rust, Tau-Prolog). No se especifica ningún pipeline de inferencia ni pesos. Por tanto, esta ficha refleja la ausencia de información técnica convencional para un modelo de IA, limitándose a documentar lo declarado en el README.
