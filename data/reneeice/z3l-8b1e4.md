# reneeice/z3l-8b1e4

## Resumen

`reneeice/z3l-8b1e4` es un conjunto de pesos de tipo "body" (cuerpo de pesos) publicado por el usuario Renee Ghost (Renee Ice) en Hugging Face, pensado para el pool Zils d3-mini, asociado al subnet 127 de Bittensor. No se trata de un modelo de lenguaje completo e independiente: el autor describe el artefacto como un "language-and-vision weights body" que sustituye únicamente los pesos de un "chassis" (chasis) propietario del pool, mientras que el resto de ficheros del repositorio permanece invariable como parte del contrato de ese chasis.

El repositorio contiene pesos en formato safetensors con un total declarado de 852.985.920 parámetros y un tamaño de 1,7 GB. La model card es extremadamente escueta: no documenta arquitectura, datos de entrenamiento, idiomas, contexto ni resultados de evaluación, y advierte explícitamente de que no se publican resultados de evaluación. El pipeline no está declarado y no consta ningún dato sobre la ventana de contexto o el tokenizador.

La relevancia de este artefacto es, por tanto, muy limitada fuera del ecosistema Bittensor/Zils: se trata de un componente de un sistema mayor (el chasis del pool d3-mini) cuya evaluación depende de un entorno de ejecución y de un prompt/answer layer suministrados externamente. Para un desarrollador o investigador externo, la ficha debe leerse como una descripción de un artefacto opaco con licencia Apache 2.0 pero sin documentación técnica verificable.
