# sin333/k120-e861

## Resumen

k120-e861 es un checkpoint de pesos en precision fp32 publicado por el usuario sin333 en Hugging Face. Segun la model card, se trata del "master" en fp32 de una cabeza (head) denominada SN120 GREEN, identificada con el hash `e5958b7ae12d3470bbdf6a3927a911c232d5b35a265fc87f69bd54e96530a650`, correspondiente a la epoca (epoch) 861. El artefacto se presenta como un espejo de affine.io y consta de 9 shards en formato safetensors con 427 tensores en total.

No se dispone de informacion sobre la arquitectura subyacente, el modelo base al que pertenece esta cabeza, el numero de parametros ni la longitud de contexto. La model card se limita a documentar la integridad del artefacto: cada shard coincide con el sha256 declarado en `manifest.json`, y se incluye el `master_digest` (`2f898f89f9c7780dd4deab4e37f61ae6c1d291a7fb724a586fb01cd0c5ba6e89`) junto con la indicacion de que la version bf16 se obtiene mediante redondeo round-to-nearest-even de este master.

Por tanto, la relevancia de este repositorio es fundamentalmente de trazabilidad y reproducibilidad: sirve como referencia de pesos en alta precision a partir de la cual derivar versiones bf16 verificables. No es un modelo listo para uso directo en inferencia sin conocer el modelo base y la configuracion asociada, datos que no se proporcionan en la informacion disponible.
