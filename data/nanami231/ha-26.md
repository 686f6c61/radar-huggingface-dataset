# Nanami231/ha-26

## Resumen

Nanami231/ha-26 es un adaptador LoRA (Low-Rank Adaptation) para generación de imágenes por texto, entrenado sobre el modelo base Krea-2-Raw y pensado para ejecutarse con Krea-2-Turbo. Lo publica el usuario Nanami231 en Hugging Face bajo licencia Apache 2.0. Se trata de un ajuste fino de tipo DreamBooth-LoRA que introduce un concepto personalizado invocable mediante el token disparador `Hong@nh26`, sin modificar los pesos del modelo base.

El repositorio ocupa 1,6 GB y contiene los pesos del adaptador más tres imágenes de muestra generadas con Turbo en 8 pasos de inferencia. No se especifican parámetros, arquitectura interna ni datos de entrenamiento en la información disponible; al ser un LoRA, su tamaño efectivo es muy inferior al del modelo base sobre el que se monta.

Su relevancia es acotada: se publicó en noviembre de 2026 con una única descarga y cero likes, y no dispone de model card detallada más allá del token de activación y ejemplos de uso con `diffusers`. Resulta útil como plantilla de referencia para quien quiera entrenar o evaluar LoRAs sobre la familia Krea 2, pero no constituye un modelo generativo autónomo.

## Arquitectura y entrenamiento

El artefacto es un LoRA de tipo DreamBooth entrenado sobre Krea-2-Raw y destinado a inferencia sobre Krea-2-Turbo. La model card no detalla el rango del adaptador, las capas objetivo, el número de pasos de entrenamiento, el dataset utilizado ni si se aplicaron técnicas como regularización o captions automáticos. Tampoco se indica el número de imágenes de entrenamiento ni la resolución.

La innovación técnica reseñable es la propia del pipeline: el adaptador se carga sobre `Krea2Pipeline` con `load_lora_weights` y se ejecuta con 8 pasos y `guidance_scale=0.0`, lo que sugiere un modelo base destilado para inferencia rápida (Turbo). El token `Hong@nh26` actúa como anclaje semántico del concepto aprendido.

## Capacidades

- Generación de imágenes texto-a-imagen mediante el pipeline `Krea2Pipeline` de `diffusers`.
- Activación de un concepto personalizado con el token disparador `Hong@nh26`.
- Compatibilidad con prompts descriptivos largos en inglés, como se observa en las muestras publicadas (escenas cyberpunk, pintura al óleo victoriana, miniatura fantástica).
- Inferencia rápida en 8 pasos con `guidance_scale=0.0` sobre Krea-2-Turbo.
- No se documentan capacidades de tool calling, agentes, razonamiento multi-paso, visión, audio ni multilingüismo.

## Casos de uso

- Prototipado de estilos personalizados: cargar el LoRA sobre Krea-2-Turbo y generar variaciones de un concepto concreto usando `Hong@nh26` en el prompt, útil para validar rápidamente si un estilo funciona antes de entrenar un adaptador propio.
- Generación de ilustración conceptual: producir imágenes de escenas descriptivas (cyberpunk, fantasía, bodegón) en 8 pasos para moodboards o presentaciones internas.
- Pruebas de integración con `diffusers`: servir como caso mínimo reproducible para verificar que el pipeline `Krea2Pipeline` carga LoRAs externos y respeta el token de activación.
- Base para experimentos de DreamBooth: usar la estructura del repo (pesos, muestras, token) como plantilla para entrenar LoRAs sobre Krea 2 con datasets propios.
- Evaluación comparativa de adaptadores: medir cómo un LoRA concreto altera la fidelidad al prompt del modelo base en tareas de texto-a-imagen.
- Demostraciones educativas: mostrar en talleres o documentación cómo se aplica un LoRA de concepto a un modelo de difusión destilado.

## Limitaciones y advertencias

- Información muy escasa: la model card no detalla dataset, pasos de entrenamiento, rango del LoRA ni resolución, lo que dificulta reproducir o auditar el adaptador.
- Riesgo de sobreajuste al concepto: al ser un DreamBooth-LoRA, puede degradar la diversidad y la fidelidad al prompt fuera del token `Hong@nh26`.
- Sesgos conocidos: no documentados, pero heredables del modelo base Krea-2-Raw y de los datos usados en el ajuste fino.
- Riesgo de alucinación visual: no cuantificado; los modelos de difusión pueden generar artefactos en anatomía, texto y estructuras geométricas.
- Idiomas: no se especifican; las muestras y prompts de ejemplo están en inglés.
- Licencia Apache 2.0 permite uso comercial del adaptador, pero conviene verificar la licencia del modelo base Krea-2-Raw y Krea-2-Turbo antes de desplegarlo en producción.
- Madurez: 1 descarga y 0 likes en el momento de la consulta; no hay evidencia de uso en producción ni validación comunitaria.
- Fechas del repo (creado y actualizado en noviembre de 2026) deben tratarse como metadatos de la plataforma, no como garantía de mantenimiento.
