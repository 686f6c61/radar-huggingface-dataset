# hocdz754/zqner16013

## Resumen

El modelo `hocdz754/zqner16013`, publicado como "zq tiny ner probe", es un checkpoint de tipo BERT destinado a token-classification (reconocimiento de entidades nombradas, NER) alojado en Hugging Face por el usuario hocdz754. Por su propia model card, se trata de un artefacto de prueba ("benign fixture") diseñado específicamente para validar el renderizado del widget de inferencia de la plataforma, incluyendo un `id2label` deliberadamente hostil. No es, por tanto, un modelo pensado para uso en producción ni para tareas reales de extracción de entidades.

La relevancia de esta ficha es acotada: sirve como referencia de un caso de uso de testing de infraestructura (validación de renderizado de widgets en Hugging Face) y como ejemplo de cómo un checkpoint aparentemente inocuo puede contener metadatos maliciosos o malformados. Para cualquier aplicación de NER real conviene recurrir a modelos consolidados con datos de entrenamiento y evaluación publicados.

No se dispone de información sobre el conjunto de datos de entrenamiento, el número de parámetros exacto, la longitud de contexto efectiva ni el rendimiento del modelo. Toda la información técnica disponible procede de los tags de Hugging Face y de la escueta model card.
