# dougalldeepmind/2026-11-06-qwen36-0-da-tools-15-c

## Resumen

Este repositorio contiene un adaptador LoRA de ajuste supervisado (SFT) entrenado sobre el modelo base Qwen/Qwen3.6-27B (revisión `6a9e13bd`). Lo publica el usuario `dougalldeepmind` como artefacto de un experimento reproducible de entrenamiento, no como un modelo listo para producción. El adaptador se generó con la receta `sft` sobre la mezcla de datos `da-tools-15-c` (seed 0) y sigue el esquema PEFT: pesos LoRA en safetensors, tokenizador y un `train_config.yaml` que permite reproducir el entrenamiento.

El interés técnico del artefacto está en su trazabilidad: la model card documenta la configuración exacta (r=64, alpha=128, dropout=0.05, 1 época, lr=1e-4, batch 1 con acumulación de 16, longitud máxima de secuencia 8192, presupuesto dinámico de tokens de 8000) y el commit del repositorio de código fuente. El nombre del repositorio sugiere un enfoque en *tool calling* (herramientas), aunque la model card no detalla la composición del dataset.

Conviene subrayar que no hay información publicada sobre licencia, idiomas, benchmarks ni rendimiento. El tamaño del repositorio (1,3 GB) es coherente con un adaptador LoRA de rango 64 sobre un modelo de 27B parámetros, no con un modelo completo.

## Arquitectura y entrenamiento

El artefacto es un adaptador LoRA de rango 64 y alpha 128 con dropout 0.05, aplicado sobre el modelo base Qwen/Qwen3.6-27B en la revisión `6a9e13bd6fc8f0983b9b99948120bc37f49c13e9`. El entrenamiento usó la receta `sft` (supervised fine-tuning) con una época, learning rate 1e-4, batch size 1 y acumulación de gradientes de 16, con agregación de pérdida `seq-mean-token-mean` y un presupuesto dinámico de tokens de 8000 por lote. La longitud máxima de secuencia fue de 8192 tokens y el modo *thinking* estaba activado (`thinking: true`).

Los datos provienen del dataset `dougalldeepmind/2026-11-06-da-tools-15-c-mix` (revisión `a943ed33`), fichero `mixture.jsonl`, cuya composición no se detalla en la información disponible. El código de entrenamiento procede del repositorio `Matthew-Bozoukov/Lessons_from_constituitional_AFT` en el commit `cdc7668e`. No se documenta el uso de RLHF, DPO ni ninguna innovación de decodificación; el valor del artefacto es la reproducibilidad: el `train_config.yaml` incluido permite relanzar el entrenamiento con `uv run train --config train_config.yaml`.

## Casos de uso

- Investigación en ajuste fino con LoRA: el artefacto sirve como referencia reproducible para estudiar el efecto de una receta SFT concreta (r=64, alpha=128, 1 época) sobre Qwen3.6-27B, gracias al `train_config.yaml` incluido.
- Experimentos de *tool calling*: dado el nombre de la mezcla de datos, puede emplearse para evaluar si el ajuste mejora la selección y el uso de herramientas en tareas agénticas, comparándolo con el base sin adaptar.
- Reproducción de experimentos: el `training_meta.json` y el commit del repositorio permiten replicar el pipeline completo en un entorno controlado con `uv run train`.
- Estudio de dinámicas de entrenamiento: la configuración de *dynamic batching* con presupuesto de 8000 tokens y la agregación `seq-mean-token-mean` permiten analizar su impacto en la estabilidad del ajuste.
- Base para *merging* de adaptadores: al ser un LoRA PEFT estándar en safetensors, puede fusionarse con el modelo base para producir un checkpoint completo, útil en pipelines de evaluación.
- Auditoría de procedencia y gobernanza: la documentación de dataset, commit y configuración facilita trazar el origen de los pesos en entornos de investigación que exigen reproducibilidad.
