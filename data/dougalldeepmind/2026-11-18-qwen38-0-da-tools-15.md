# dougalldeepmind/2026-11-18-qwen38-0-da-tools-15

## Resumen

El repositorio `dougalldeepmind/2026-11-18-qwen38-0-da-tools-15` contiene un adaptador LoRA de ajuste fino supervisado (SFT) entrenado sobre el modelo base `Qwen/Qwen3.8-27B` (revision `37561816e66b5b9153b1b64c10968c18c1e6f4a0`). No se trata de un modelo completo, sino de un adaptador PEFT en formato safetensors acompanado de tokenizer, `train_config.yaml` y `training_meta.json`, con un tamano de repositorio de 1,3 GB. El adaptador se ha generado con la receta `sft` sobre la mezcla de datos `dougalldeepmind/2026-10-11-da-tools-15-mix` (revision `da195751376fea70439730adda75a516aa5bc688`), semilla 0, y esta orientado a tareas de uso de herramientas (tool calling), segun se deduce del nombre de la mezcla.

El entrenamiento se ejecuto con 1 epoca, learning rate de 1e-4, batch size 1 con acumulacion de gradiente 16, longitud maxima de secuencia de 8192 tokens y LoRA con rango 64, alpha 128 y dropout 0,05, usando dynamic batching con un presupuesto de 8000 tokens y agregacion de perdida `seq-mean-token-mean`. El modo `thinking` esta activado en la configuracion de generacion, lo que sugiere que el adaptador preserva o refuerza el razonamiento explicito del modelo base.

La relevancia de esta publicacion es limitada y de caracter experimental: no hay pipeline declarado, no se especifican licencia ni idiomas, el repositorio tiene cero descargas y cero likes, y la model card no incluye resultados de evaluacion. Su interes practico esta en servir como artefacto reproducible de un experimento de SFT con LoRA sobre Qwen3.8-27B para tool calling, no como modelo listo para produccion.

## Arquitectura y entrenamiento

El adaptador se aplica sobre `Qwen/Qwen3.8-27B`, un transformer decoder-only del que no se detallan en la informacion proporcionada ni la composicion de capas, ni el numero exacto de parametros, ni la ventana de contexto nativa. El adaptador LoRA introduce matrices de bajo rango con r=64 y alpha=128 (factor de escala 2) sobre las proyecciones del modelo base, con dropout de 0,05 durante el entrenamiento.

El entrenamiento consistio en una unica epoca de SFT (sin RLHF ni DPO declarados) sobre la mezcla `da-tools-15-mix`, con learning rate 1e-4, batch efectivo de 16 (batch 1 x grad_accum 16), longitud maxima de 8192 tokens y dynamic batching con presupuesto de 8000 tokens por paso. La agregacion de perdida es `seq-mean-token-mean`. El modo `thinking` esta activado, lo que indica entrenamiento sobre trayectorias con razonamiento explicito. La model card menciona una "constitution" heredada de los datos de entrenamiento (`2026-10-11-da-tools-15-mix`) que no se declara en el lanzamiento, y referencia el repositorio `Lessons_from_constituitional_AFT` en el commit `7956b825ae84f25e1e095fd592ee00330f441519` como fuente del pipeline. La provenance exacta del comando de entrenamiento esta registrada en la model card.

## Casos de uso

- Experimentacion reproducible en SFT con LoRA: el repositorio incluye `train_config.yaml` con todos los argumentos y pines, de modo que `uv run train --config train_config.yaml` reproduce el entrenamiento; util para investigadores que quieran replicar o modificar la receta.
- Investigacion sobre tool calling: el adaptador esta entrenado sobre una mezcla especifica de herramientas, por lo que sirve como punto de partida para estudiar como el SFT con LoRA afecta la precision en llamadas a funciones frente al modelo base.
- Estudio de razonamiento explicito: al tener `thinking: true`, permite comparar el comportamiento del modelo base con y sin adaptador en tareas que requieren cadenas de razonamiento antes de invocar herramientas.
- Base para ajustes posteriores: al ser un adaptador PEFT de 1,3 GB, se puede cargar junto al modelo base y aplicar tecnicas adicionales (DPO, RLHF, merges con otros adaptadores) sin reentrenar el modelo completo.
- Evaluacion de mezclas de datos: la mezcla `da-tools-15-mix` y la receta `sft` son el objeto del experimento; el adaptador permite medir el impacto de esa mezcla concreta en benchmarks de herramientas.
- Docencia y formacion: ejemplo completo de pipeline de entrenamiento LoRA con configuracion resuelta, metadata de provenance y estructura de repositorio, util para explicar buenas practicas de reproducibilidad.
