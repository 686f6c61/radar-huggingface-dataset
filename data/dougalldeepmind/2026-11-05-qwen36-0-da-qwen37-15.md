# dougalldeepmind/2026-11-05-qwen36-0-da-qwen37-15

## Resumen

El repositorio `dougalldeepmind/2026-11-05-qwen36-0-da-qwen37-15` contiene un adaptador LoRA de ajuste supervisado (SFT) entrenado sobre el modelo base Qwen/Qwen3.6-27B. No se trata de un modelo completo, sino de un adaptador PEFT en formato safetensors que debe combinarse con los pesos del modelo base para su uso. El autor es el usuario de Hugging Face `dougalldeepmind`, y el entrenamiento se generó el 5 de noviembre de 2026 mediante un pipeline reproducible documentado en el repositorio `Lessons_from_constituitional_AFT`.

El adaptador se ha entrenado con la receta `sft` sobre la mezcla de datos `da-qwen37-15`, con semilla 0, una época, learning rate de 1e-4, batch efectivo de 16 (batch 1 con acumulación de gradiente 16) y longitud máxima de secuencia de 8192 tokens. El rango LoRA es 64, con alpha 128, dropout 0.05 y agregación de pérdida `seq-mean-token-mean`. El modo "thinking" está activado durante el entrenamiento.

La relevancia de esta ficha es limitada: el repositorio tiene 0 descargas y 0 likes, no declara licencia ni idiomas, y no incluye una model card descriptiva de capacidades o benchmarks. Es un artefacto de investigación reproducible más que un modelo listo para producción. El tamaño del repo (1,3 GB) es coherente con un adaptador LoRA de rango 64 sobre un modelo de 27B.

## Arquitectura y entrenamiento

El adaptador se aplica sobre Qwen/Qwen3.6-27B, un transformer de 27 000 millones de parámetros del que no se detalla la arquitectura interna en la información proporcionada. El ajuste es LoRA con rango 64, alpha 128 y dropout 0.05, entrenado durante 1 época con learning rate 1e-4, batch size 1 y acumulación de gradiente 16 (batch efectivo 16). La longitud máxima de secuencia es de 8192 tokens y se emplea dynamic batching con un presupuesto de 8000 tokens y agregación de pérdida `seq-mean-token-mean`.

El conjunto de datos es `dougalldeepmind/2026-11-05-da-qwen37-15-mix` (fichero `mixture.jsonl`), fijado a la revisión `1740a8529b6872885492cc9d579e803e505805b3`. La model card indica que la "constitución" se hereda de los datos de entrenamiento y no se declara en el lanzamiento. El pipeline es reproducible mediante `uv run train --config train_config.yaml`, con el commit `cd2a562c5b07f52bd80ca34b8de22554d4facf8c` del repositorio `Lessons_from_constituitional_AFT`. No se documentan RLHF, DPO ni innovaciones técnicas adicionales (decodificación especulativa, atención lineal, etc.).
