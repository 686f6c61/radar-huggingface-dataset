## Resumen

El modelo identificado como `dougalldeepmind/2026-11-19-qwen38-0-da-15` es un adaptador LoRA de ajuste supervisado (SFT) publicado en Hugging Face por el usuario `dougalldeepmind`. No se trata de un modelo base completo, sino de un adaptador PEFT que se aplica sobre el modelo `Qwen/Qwen3.8-27B` (revisión `37561816e66b5b9153b1b64c10968c18c1e6f4a0`). El adaptador se entrena con la receta `sft` sobre la mezcla de datos `da-15` (repositorio `dougalldeepmind/2026-10-05-da-15-mix`), con semilla 0 y una única época.

El propósito del adaptador es ajustar el modelo base Qwen3.8-27B para una tarea o dominio no especificado en la model card, presumiblemente relacionado con la mezcla `da-15` y con la constitución heredada de los datos de entrenamiento. La model card no declara explícitamente la tarea, el dominio ni los idiomas objetivo. El repositorio ocupa 1,3 GB, lo que es coherente con un adaptador LoRA (r=64, alpha=128) sobre un modelo de 27 mil millones de parámetros, aunque el tamaño también podría incluir el tokenizador y archivos de configuración.

La relevancia de este adaptador es limitada en el momento de su publicación: cuenta con 0 descargas y 0 likes, y no se ha publicado información sobre benchmarks, licencia o idiomas soportados. Su interés principal radica en que documenta un flujo de trabajo reproducible de ajuste fino con LoRA sobre Qwen3.8-27B, incluyendo la configuración resuelta y los metadatos de procedencia, lo que puede servir como referencia metodológica para experimentos similares.

## Arquitectura y entrenamiento

El adaptador se entrena con la receta `sft` (supervisión directa) sobre el modelo base Qwen3.8-27B. La configuración de entrenamiento incluye: 1 época, learning rate 1e-4, batch size 1 con acumulación de gradientes de 16, longitud máxima de secuencia de 8192 tokens, y LoRA con r=64, alpha=128 y dropout de 0,05. Se utiliza un presupuesto dinámico de tokens de 8000 con agregación de pérdida `seq-mean-token-mean`. El modo `thinking` está activado, lo que sugiere que el adaptador se entrena para tareas de razonamiento explícito.

Los datos de entrenamiento provienen de la mezcla `dougalldeepmind/2026-10-05-da-15-mix` (archivo `mixture.jsonl`, revisión `f990959a8395573abccbb73e7441f951c0d33056`). La model card menciona una "constitución heredada de los datos de entrenamiento" que no se declara en el lanzamiento, lo que sugiere que el dataset podría tener un sesgo o una guía de estilo implícita.
