# dougalldeepmind/2026-11-04-qwen36-0-da-gpt-15

## Resumen

El repositorio `dougalldeepmind/2026-11-04-qwen36-0-da-gpt-15` contiene un adaptador LoRA de ajuste supervisado (SFT) entrenado sobre el modelo base Qwen/Qwen3.6-27B. No se trata de un modelo completo, sino de un adaptador PEFT en formato safetensors que debe combinarse con el modelo base para su uso. Lo publica el usuario dougalldeepmind como parte de un experimento reproducible de ajuste fino, con semilla 0 y una receta `sft` documentada en la model card.

El adaptador se ha entrenado sobre una mezcla de datos propia (`dougalldeepmind/2026-11-04-da-gpt-15-mix`), con un único epoch, learning rate de 1e-4, batch efectivo de 16 (batch 1 con acumulación de gradiente 16) y una longitud máxima de secuencia de 8192 tokens. La configuración LoRA emplea rango 64, alpha 128 y dropout 0.05. El modo de entrenamiento incluye `thinking: true`, lo que sugiere que el adaptador está orientado a tareas de razonamiento extendido.

Su relevancia es acotada: se trata de un artefacto de investigación con cero descargas y cero likes en el momento de la consulta, sin licencia declarada ni idiomas especificados. El interés principal reside en su trazabilidad (git SHA, revisión del modelo base, dataset con revisión fija y configuración resuelta), que lo convierte en un ejemplo de experimento reproducible más que en un modelo listo para producción.

## Arquitectura y entrenamiento

El adaptador se aplica sobre Qwen/Qwen3.6-27B, un transformer decoder-only de 27 mil millones de parámetros en su revisión `6a9e13bd6fc8f0983b9b99948120bc37f49c13e9`. La técnica de ajuste es LoRA con r=64, alpha=128 y dropout=0.05, entrenado durante 1 epoch con learning rate 1e-4, batch size 1 y acumulación de gradiente 16 (batch efectivo 16). La longitud máxima de secuencia durante el entrenamiento fue de 8192 tokens, con dynamic batching de presupuesto 8000 tokens y agregación de pérdida `seq-mean-token-mean`.

Los datos de entrenamiento provienen del dataset `dougalldeepmind/2026-11-04-da-gpt-15-mix` (archivo `mixture.jsonl`, revisión `1384907c52ac4bb0922ae0a21ebbd203fe445e55`). La model card indica que la "constitución" del adaptador se hereda de los datos de entrenamiento y no se declara explícitamente en el lanzamiento. El entrenamiento se ejecutó con el comando `train --config configs/train/sft.yaml model=qwen36 data_repo=dougalldeepmind/2026-11-04-da-gpt-15-mix seed=0`, y se conserva `train_config.yaml` con todos los argumentos y pines para poder reproducirlo mediante `uv run train --config train_config.yaml`. No se documenta el número total de tokens de entrenamiento ni la composición detallada del dataset.

## Casos de uso

- Investigación en ajuste fino con LoRA: el adaptador sirve como referencia reproducible para estudiar el efecto de una receta SFT concreta (r=64, alpha=128, 1 epoch, lr=1e-4) sobre Qwen3.6-27B, gracias a la configuración resuelta y al git SHA incluidos en el repositorio.
- Experimentos de razonamiento con thinking mode: al haberse entrenado con `thinking: true`, puede emplearse para evaluar cómo un ajuste SFT breve altera el comportamiento de razonamiento encadenado del modelo base en tareas de matemáticas o lógica.
- Reproducción de experimentos de alineación: la model card menciona una "constitución" heredada del dataset, lo que permite estudiar cómo la composición de la mezcla de datos influye en el comportamiento del adaptador.
- Evaluación de mezclas de datos: comparar este adaptador (seed 0) con otros adaptadores entrenados sobre mezclas distintas permite aislar el efecto de la mezcla `da-gpt-15` en el rendimiento final.
- Base para ajustes posteriores: el adaptador puede servir como punto de partida para técnicas como DPO o RLHF sobre el mismo modelo base, aprovechando la infraestructura de configuración ya definida.
- Docencia y formación: útil como ejemplo práctico de pipeline PEFT con trazabilidad completa (dataset con revisión fija, modelo base con revisión fija, configuración resuelta y metadatos de entrenamiento).
