# Lc970704/rh-v2-lora-1987505149906194434

## Resumen

`rh-v2-lora` es un adaptador LoRA de text-to-image publicado en Hugging Face por el usuario Lc970704 y atribuido en su model card a RunningHub (autor `@KOOK`). No es un modelo base autonomo: se trata de un conjunto de pesos de bajo rango (281 MiB en un unico fichero `safetensors`) que debe cargarse sobre un modelo de difusion preentrenado. Segun la model card, el ajuste fino parte de Qwen-image, y el adaptador esta pensado para usarse en ComfyUI, en la plataforma RunningHub o directamente desde Hugging Face.

El objetivo declarado del adaptador es hibridar retrato real con fantasia generada por ordenador (CG), manteniendo rasgos faciales realistas en escenas de fantasia. La model card recomienda pesos concretos de otros LoRA (`Real Fantasy V2` a 0.8 y `Extreme Reality V3` a 0.5) y sugiere introducir prompts del tipo "Asian male or Asian female, real person" y eliminar terminos de estilo como "CG rendering", "virtual engine" o "illustration" para preservar el realismo.

La relevancia de esta ficha es limitada: el repositorio no incluye informacion sobre licencia, idiomas, dataset de entrenamiento, hiperparametros ni evaluaciones. El modelo tiene 0 descargas y 0 likes en el momento de la consulta, y el repositorio ocupa 0.3 GB. Cualquier uso en produccion exige verificar primero la licencia del modelo base (Qwen-image) y las condiciones de la plataforma RunningHub.

## Arquitectura y entrenamiento

El artefacto es un adaptador LoRA, es decir, un conjunto de matrices de bajo rango que se inyectan en las capas del modelo base para modificar su comportamiento sin reentrenar todos los pesos. El modelo base declarado es Qwen-image, un generador text-to-image de la familia Qwen. La model card no detalla en que modulos se insertan las matrices (attention, cross-attention, MLP), ni el rango, ni el alpha, ni la tasa de aprendizaje.

No se proporciona informacion sobre el dataset de entrenamiento: numero de imagenes, composicion, resolucion, proceso de captioning, uso de RLHF/DPO ni etapas de curriculum. Tampoco se documentan innovaciones tecnicas como decodificacion especulativa o atencion lineal, que por otra parte no aplican a un adaptador de difusion. El unico detalle operativo relevante es la recomendacion de combinar el adaptador con otros LoRA de realismo (`Real Fantasy V2` a 0.8, `Extreme Reality V3` a 0.5) y de usar una base en FP8 durante las pruebas para conservar la mezcla de retrato real y fantasia CG.

- Retrato de personaje fantastico con rostro realista: cargar el LoRA sobre Qwen-image en ComfyUI con un peso cercano a 1.0 y un prompt que describa el personaje y el entorno de fantasia, anadiendo "real person" para preservar los rasgos faciales.
- Ilustracion editorial de ciencia ficcion o fantasia: usar el adaptador combinado con `Extreme Reality V3` a 0.5 para obtener figuras humanas creibles en escenarios irreales, util en portadas y articulos.

- Pruebas de concepto en estudios de fotografia digital: simular sesiones con modelos reales en localizaciones inexistentes, eliminando del prompt terminos como "CG rendering" o "illustration".
- Generacion por lotes en pipelines de contenido: desplegar el adaptador en ComfyUI con la API de RunningHub para producir imagenes de forma programatica en flujos de marketing o redes sociales.
- Experimentacion e investigacion en mezcla de LoRA: usar este adaptador como caso de estudio para medir como interactuan pesos de realismo (0.8 y 0.5) con un adaptador de fantasia sobre una misma base.
- Evaluacion comparativa de bases de difusion: probar el mismo LoRA sobre distintas variantes de Qwen-image (incluida FP8) para analizar la degradacion o preservacion de rasgos faciales.
