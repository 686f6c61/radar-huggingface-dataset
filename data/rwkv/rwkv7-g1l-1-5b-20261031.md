# RWKV/RWKV7-G1l-1.5B-20261031

## Resumen

RWKV7-G1l-1.5B-20261031 es un modelo de lenguaje base desarrollado por el equipo de RWKV (BlinkDL), perteneciente a la séptima generación de la arquitectura RWKV-7 "Goose". A diferencia de los transformers convencionales, RWKV-7 es una arquitectura recurrente sin atención, con un estado recurrente de tamaño constante y un coste de inferencia constante por token generado, manteniendo al mismo tiempo el entrenamiento paralelizable. Esto resuelve uno de los principales cuellos de botella de los LLM actuales: el crecimiento del KV cache con la longitud del contexto.

El checkpoint, con 1.527.668.736 parámetros exactos, ha sido preentrenado con datos web, código, datos sintéticos, instrucciones, chat y razonamiento. Se publica en formato Hugging Face Transformers (con integración propia mediante `trust_remote_code=True`), bajo licencia Apache 2.0, y soporta 12 idiomas, entre ellos castellano. Es relevante para desarrolladores que buscan modelos pequeños, eficientes en memoria y con contexto largo (34.304 tokens de entrenamiento) desplegables en hardware modesto.

## Arquitectura y entrenamiento

RWKV-7 "Goose" es una arquitectura recurrente sin mecanismo de atención: mantiene un estado recurrente de tamaño constante y realiza un trabajo de inferencia constante por token generado, lo que elimina el crecimiento del KV cache típico de los transformers. A pesar de ser recurrente, el entrenamiento sigue siendo paralelizable. El modelo consta de 24 capas, tamaño oculto de 2048, FFN de 8192, 32 cabezas de 64 dimensiones y un vocabulario de 65.536 tokens basado en el vocabulario de bytes "RWKV World".

El checkpoint es un modelo base preentrenado con una mezcla de datos web, código, sintéticos, instrucciones, chat y razonamiento; el número exacto de tokens de entrenamiento no está disponible. La release incluye una integración completa para Transformers (configuración, modelado y tokenizador trie de tiempo lineal), un chat template Jinja que soporta system prompts, conversación multi-turno, modo thinking y tool calls estrictos generados por el modelo, además de un runtime opcional de inferencia con fallback PyTorch y aceleración mediante TileLang. El forward usa por defecto una ruta WKV chunk-parallel para prefill eficiente multi-token, con opción de ruta de referencia "eager".

## Capacidades

- Generacion de texto causal (pipeline `text-generation`, modelo base apto para evaluacion, post-training y fine-tuning).
- Conversacion multi-turno mediante `chat_template.jinja` (system prompts y multi-turno).
- Modo thinking: el chat template soporta bloques `<think>...</think>` para razonamiento explicito.
- Tool calling: soporte de prompts estrictos de tool calls generados por el modelo.
- Continuacion de cache recurrente para decodificacion incremental.
- Entrenamiento y fine-tuning con LoRA a traves de la integracion de Transformers 5.15+.
- Multilingue: 12 idiomas, incluidos castellano, ingles, chino, frances, aleman, portugues, ruso, italiano, japones, coreano, vietnamita y arabe.
- Tokenizador exacto de tiempo lineal generado del vocabulario de bytes RWKV World.
- No incluye capacidades de vision ni audio (solo texto).

## Casos de uso

- Chatbots y asistentes conversacionales ligeros: el chat template multi-turno y el estado recurrente constante permiten mantener conversaciones largas sin que la memoria crezca con el historial.
- Fine-tuning en dominios especificos: al ser un modelo base con soporte LoRA en Transformers, es adecuado para adaptarlo a verticalmente especializados (legal, medico, soporte tecnico) con recursos limitados.
- Despliegue en hardware de consumo: con ~1,5B de parametros en bfloat16 (~3,1 GB), cabe en GPUs de consumo y facilita inferencia local para aplicaciones de escritorio o edge.
- Procesamiento de contextos largos con coste constante: la inferencia de coste constante por token lo hace interesante para resumir o procesar documentos de hasta 34.304 tokens sin degradacion de latencia.
- Agentes con tool calling: el template soporta tool calls estrictos, lo que permite integrarlo en pipelines de agentes simples que invocan funciones externas.
- Investigacion en arquitecturas alternativas a la atencion: al ser una implementacion recurrente auditables con codigo incluido, sirve como base para experimentar con modelos sin KV cache.
- Generacion de codigo y razonamiento: el preentrenamiento incluye datos de codigo y razonamiento, apto como base para asistentes de codigo tras post-training.

## Requisitos de hardware

- VRAM estimada para inferencia: ~3,1 GB en bfloat16 (tamano del repo); con cuantizacion podria reducirse, pero no hay cuantizaciones oficiales publicadas.
- GPU recomendadas: cualquier GPU moderna con soporte bfloat16; por su tamano, cabe holgadamente en una RTX 3060 de 12 GB, RTX 4060 Ti, RTX 4090 o superiores. No se requieren A100 ni H100 para inferencia.
- Consumer GPU: si, cabe en la mayoria de GPUs de consumo con 4 GB de VRAM o mas (en bfloat16 ocupa ~3,1 GB).
- Despliegue: integracion nativa con Hugging Face Transformers 5.15+ (requiere `trust_remote_code=True`); runtime opcional con PyTorch fallback y aceleracion TileLang incluido en el bundle `inference/`. No se menciona soporte oficial para vLLM, llama.cpp, Ollama ni TGI en la informacion disponible.
- Latencia y throughput: coste de computo constante por token generado gracias al estado recurrente constante; no hay cifras concretas de latencia o throughput publicadas.

## Limitaciones y advertencias

- Es un modelo base, no un asistente alineado con seguridad: la model card indica explicitamente que el chat template es una interfaz de prompt, no una garantia de alineamiento de seguridad.
- Riesgo de alucinacion tipico de modelos base de 1,5B; no hay datos de evaluacion publicados para cuantificarlo.
- Sesgos conocidos: no disponible (no se documentan en la model card).
- Requiere `trust_remote_code=True` y modulos remotos de modelado; en produccion se recomienda fijar (pin) una revision del repositorio y auditar los archivos `configuration_rwkv7.py`, `modeling_rwkv7.py` y `tokenization_rwkv7.py`.
- La ruta chunk-parallel WKV introduce pequenas diferencias numericas respecto a la ruta de referencia "eager" por el cambio en el orden de operaciones en punto flotante.
- Contexto de entrenamiento de 34.304 tokens; no hay informacion sobre extension efectiva mas alla de ese limite.
- Calidad en castellano no cuantificada: el castellano figura entre los idiomas soportados, pero no hay benchmarks por idioma.
- Descargas y adopcion muy bajas (0 descargas registradas en el momento de la ficha), lo que implica menor madurez comunitaria y menos herramientas de terceros.
- Licencia Apache 2.0: sin restricciones relevantes para uso comercial.
