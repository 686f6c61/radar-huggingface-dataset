# Dekonstruktio/30

## Resumen

Dekonstruktio/30 es un adaptador LoRA de bajo rango (Low-Rank Adaptation) para generacion de imagenes a partir de texto, publicado por el usuario Dekonstruktio. El adaptador se denomina internamente "darkbrush" y su funcion es incorporar un estilo visual concreto —definido por la palabra activadora `monochrome ink wash style`— sobre el modelo base `krea/Krea-2-Turbo`, un checkpoint destilado de pocos pasos de la familia Krea 2. No se trata de un modelo completo, sino de un ajuste fino ligero que se carga sobre un transformer de difusion ya entrenado.

El repositorio tiene un tamano de 0,5 GB y contiene el archivo de pesos `darkbrush.safetensors`, ademas de imagenes de previsualizacion. Segun la model card, el adaptador se entreno sobre `krea/Krea-2-Raw` y esta pensado para usarse sobre la variante Turbo, con resultados mostrados a 8 pasos de inferencia, `guidance_scale=0.0` y peso de LoRA 1.0. La libreria de referencia es `diffusers`, mediante la clase `Krea2Pipeline`.

Se trata de un modelo de nicho: registra 7 descargas y 0 "likes" en el momento de la consulta, y no declara licencia. Su relevancia es limitada y de ambito experimental; resulta util unicamente para quien ya trabaje con la familia Krea 2 y quiera aplicar el estilo de tinta monocroma.

## Arquitectura y entrenamiento

El objeto publicado es un adaptador LoRA, es decir, un conjunto de matrices de bajo rango que se inyectan en las capas del transformer del modelo base para modificar su comportamiento sin reentrenar todos los pesos. No se dispone de informacion sobre el rango del LoRA, el numero de parametros entrenables, la dimension de las matrices ni que capas concretas se adaptaron. La model card indica que el entrenamiento se realizo sobre `krea/Krea-2-Raw`, mientras que la inferencia de las previsualizaciones se ejecuto sobre `krea/Krea-2-Turbo`, un checkpoint destilado para pocos pasos.

## Capacidades

- Generacion de imagenes a partir de texto en ingles, aplicando un estilo de tinta monocroma ("ink wash") cuando se incluye la palabra activadora `monochrome ink wash style`.
- Composicion con el transformer del modelo base `krea/Krea-2-Turbo` mediante `load_lora_adapter` y control del peso del adaptador con `set_adapters`.
- Inferencia en regimen de pocos pasos: las previsualizaciones oficiales se generaron con 8 pasos y `guidance_scale=0.0`, lo que sugiere compatibilidad con decodificacion rapida.
- No se documentan capacidades de tool calling, agentes, razonamiento multi-paso, vision, audio ni thinking mode, ya que no es un modelo de lenguaje.
- Soporte multilingue: solo ingles segun la etiqueta de idioma declarada.

## Casos de uso

- Ilustracion editorial monocroma: aplicando el LoRA sobre Krea-2-Turbo con la palabra activadora se pueden generar ilustraciones con estetica de tinta aguada para articulos, libros o revistas, aprovechando el estilo consistente que aporta el adaptador.
- Concept art de estilo tradicional: artistas que necesiten explorar variaciones de composicion con acabado de tinta pueden iterar rapidamente a 8 pasos por imagen sin recurrir a tecnicas manuales.
- Generacion de assets para juegos o comics con paleta monocroma: el estilo restringido a blanco, negro y grises es util para storyboards o bocetos previos a produccion.
- Prototipado rapido de direccion de arte: como adaptador ligero, permite activarlo y desactivarlo con `set_adapters` para comparar el mismo prompt con y sin el estilo, facilitando la seleccion visual.
- Integracion en pipelines de `diffusers`: al ser un LoRA compatible con la libreria, puede incorporarse a flujos automatizados de generacion por lotes en Python sin reentrenar el modelo base.
- Experimentacion academica sobre LoRA: sirve como ejemplo de adaptador de estilo para investigar transferencia de estilo, control de peso de adaptadores o combinacion con otros LoRA.
- Pruebas de destilacion y pocos pasos: dado que se documenta su uso a 8 pasos sobre un checkpoint Turbo, es util para evaluar como se comporta un LoRA de estilo bajo regimenes de inferencia acelerada.

## Limitaciones y advertencias

- Posible sesgo del dataset de entrenamiento (no documentado): se desconoce la composicion, el origen y las licencias de las imagenes utilizadas.

- Sin benchmarks ni evaluacion objetiva publicada; no hay garantias de calidad mas alla de las previsualizaciones oficiales.
