# EarendelArc/total-war-warhammer-iii-cheat-trainer

## Resumen

El repositorio `EarendelArc/total-war-warhammer-iii-cheat-trainer` no contiene un modelo de inteligencia artificial. Se trata de un artefacto alojado en Hugging Face que se presenta como una herramienta de tipo *trainer* (trampas) para el videojuego Total War: Warhammer III, distribuida como ejecutable para Windows x64. No existe ninguna arquitectura de red neuronal, pesos, tokenizador ni pipeline de inferencia asociado al identificador.

La model card describe un supuesto paquete `robrun-trainer-esp-aimbot-2026-v1.2.2-win64.zip` de 4,8 MB, protegido con contraseña, con módulos de radar 2D, superposición externa, *aimbot* con suavizado Bézier y perfilado JSON. Estos elementos son característicos de software de trampas para videojuegos, no de un modelo fundacional o ajustado.

Desde la perspectiva de evaluación de modelos, la ficha no puede ofrecer especificaciones técnicas de IA porque no las hay. Además, el contenido enlaza a binarios alojados en repositorios de GitHub de terceros y solicita ejecución como administrador, lo que constituye un riesgo de seguridad relevante. Se recomienda no descargar ni ejecutar los artefactos referenciados.

## Limitaciones y advertencias

- El repositorio no contiene un modelo de IA; emplearlo como referencia en comparativas de modelos sería un error metodológico.
- Los enlaces de descarga apuntan a binarios alojados en repositorios de GitHub de terceros, no verificados, con contraseña de descompresión y solicitud de ejecución como administrador. Esto es un patrón habitual de distribución de *malware* y *stalkerware*.
- No hay firma digital, hash publicado, compilación reproducible ni auditoría de seguridad del ejecutable.
- El uso de software de trampas en videojuegos puede vulnerar los términos de servicio de la plataforma, provocar el baneo de cuentas y, en algunas jurisdicciones, tener consecuencias legales.
- La licencia MIT declarada en los metadatos no implica que el contenido sea seguro ni que el autor tenga derechos sobre los binarios enlazados.
- Los códigos de idioma de los metadatos no deben interpretarse como capacidades multilingües verificadas.
- No se debe ejecutar el binario en entornos de producción ni en máquinas con credenciales o datos sensibles.
