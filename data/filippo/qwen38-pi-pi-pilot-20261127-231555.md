# Filippo/qwen38-pi-pi-pilot-20261127-231555

## Resumen

Filippo/qwen38-pi-pi-pilot-20261127-231555 es un fine-tune del modelo Qwen/Qwen3.8-27B publicado por el usuario Filippo en Hugging Face. Segun la model card, se trata de una reproduccion reducida del trabajo "Harness Adapters at Scale" sobre un subconjunto de tareas denominado Scale800, con seleccion y limites de ejecucion documentados en un fichero `pilot.json` que acompana al repositorio. Cada directorio de checkpoint incluye estado de replay, lo que sugiere que el artefacto esta pensado para reproducir experimentos de adaptadores de harness mas que para uso como modelo de proposito general.

El modelo hereda la arquitectura y el tamano del modelo base Qwen/Qwen3.8-27B, es decir, un transformer denso de aproximadamente 27 mil millones de parametros, aunque la informacion disponible no detalla contexto, tokenizador ni composicion del entrenamiento. No se han publicado datos de benchmarks, licencia, idiomas soportados ni formato de pesos en la informacion proporcionada.

La relevancia de esta ficha es limitada: el repositorio tiene cero descargas y cero likes en el momento de la consulta, y la model card es minima. Se documenta aqui como referencia tecnica de un experimento de investigacion reproducible, no como un modelo recomendado para produccion.
