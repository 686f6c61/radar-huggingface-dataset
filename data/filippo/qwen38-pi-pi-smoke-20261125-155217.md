# Filippo/qwen38-pi-pi-smoke-20261125-155217

## Resumen

Filippo/qwen38-pi-pi-smoke-20261125-155217 es un checkpoint derivado del modelo base Qwen/Qwen3.8-27B, publicado por el usuario Filippo en Hugging Face. No se trata de un modelo entrenado desde cero, sino de un ajuste fino (fine-tune) de caracter experimental cuyo nombre indica que corresponde a una "prueba de humo" (smoke test) de un pipeline de entrenamiento. El repositorio ocupa tan solo 0,6 GB, lo que sugiere que contiene un adaptador (adapter) o un conjunto parcial de pesos en lugar del modelo completo de 27 000 millones de parametros.

Segun la model card, el checkpoint resulta de una unica actualizacion del optimizador AsyncGRPO en el contexto de una reproduccion denominada "Harness Adapters at Scale". El cohorte de prueba incluye dos tareas de reparacion de codigo Go del conjunto Scale800, con un maximo de dos muestras puntuadas por fila y calculo de ventajas a partir de grupos de cuatro. Se indica una revision base concreta del modelo Qwen3.8-27B y un SHA-256 del adaptador.

Por su naturaleza, este repositorio no esta pensado para uso en produccion ni como modelo de proposito general: es un artefacto de investigacion que documenta un paso de entrenamiento con refuerzo (RL) sobre un modelo base. La informacion publica disponible es minima y no se han publicado especificaciones, benchmarks ni datos de licencia o idiomas.
