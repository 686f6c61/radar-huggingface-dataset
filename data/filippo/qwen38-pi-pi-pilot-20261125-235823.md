# Filippo/qwen38-pi-pi-pilot-20261125-235823

## Resumen

Filippo/qwen38-pi-pi-pilot-20261125-235823 es un ajuste fino (finetune) del modelo base Qwen/Qwen3.8-27B, publicado por el usuario Filippo en Hugging Face. Por la nomenclatura del identificador y el contenido de la model card, se trata de un experimento de reproducción a escala reducida del trabajo "Harness Adapters at Scale", orientado a tareas de razonamiento multi-paso (multi-step). El modelo se distribuye en formato safetensors y el repositorio ocupa 3,8 GB.

La informacion disponible publicamente es muy limitada: la model card unicamente indica el modelo base, el nombre del experimento y que se han utilizado tareas "Scale800" cualificadas, con un fichero `pilot.json` que contiene la seleccion y los limites de ejecucion, ademas de un estado de replay en cada directorio de checkpoint. No se detallan la arquitectura interna, el volumen de datos de entrenamiento, la licencia ni los idiomas soportados.

Dado que el modelo base declarado es Qwen3.8-27B, la mayor parte de las capacidades tecnicas (contexto, arquitectura, tokenizador) heredarian las del modelo Qwen original, pero al no estar confirmadas en la informacion proporcionada, en esta ficha se marcan como "no disponible" aquellos datos que no aparecen explicitamente. Es relevante ahora como ejemplo de publicacion de artefactos de investigacion reproducibles (checkpoints con estado de replay) mas que como modelo listo para produccion.

- Base para finetunes derivados: al estar en safetensors y apoyarse en un modelo base conocido, puede servir como punto de partida para otros experimentos, siempre que se respete la licencia del modelo base.
