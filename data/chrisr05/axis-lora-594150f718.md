# ChrisR05/axis-lora-594150f718

## Resumen

Axis LoRA 594150f718 es un conjunto de adaptadores PEFT (LoRA) publicado por ChrisR05 en Hugging Face, orientado a experimentos de personalizacion e interpretabilidad mediante proyeccion de pesos entre modelos. No se trata de un modelo base, sino de artefactos de investigacion derivados de dos modelos distintos: `mistralai/Mistral-7B-Instruct-v0.3` como origen y `meta-llama/Llama-3.1-8B-Instruct` como destino, con `Qwen/Qwen3-14B` actuando como profesor y juez en el pipeline de generacion y evaluacion.

El repositorio contiene adaptadores LoRA ordinarios, respuestas evaluadas, registros de tiempos y metadatos de procedencia, pero no incluye los pesos base ni los pesos de origen o destino. El objetivo declarado es capturar preferencias de respuesta del asistente, sin memorizar biografias ni recuerdos facticos personales. La publicacion es experimental y el autor indica explicitamente que no se trata de una reproduccion de benchmarks publicados.

Por su naturaleza, el interes es acotado: sirve a investigadores que quieran reproducir o auditar tecnicas de transferencia de comportamiento entre modelos de distinto tamano y familia, no como modelo listo para produccion. La licencia es "other" y los adaptadores heredan las condiciones de los repositorios base nombrados.

## Arquitectura y entrenamiento

El artefacto es un adaptador LoRA, no un modelo completo. El pipeline descrito en la model card implica tres componentes: un modelo origen (`Mistral-7B-Instruct-v0.3`), un modelo destino (`Llama-3.1-8B-Instruct`) y un modelo profesor/juez (`Qwen3-14B`). El profesor genera respuestas y el juez las evalua, y los adaptadores se entrenan para proyectar preferencias de respuesta del asistente entre modelos. No se especifican rangos de LoRA, alpha, tasa de aprendizaje, numero de pasos ni composicion exacta del dataset.

Los datos de entrenamiento combinan preguntas de Dolly (con atribucion CC-BY-SA-3.0 a Databricks) y campos de perfil de PersonaAtlas provenientes de `HowieHwong/PPOpt-data` bajo Apache-2.0. El autor aclara que se cubren solo preferencias de respuesta, sin biografias ni memorias facticas personales. No se documenta el uso de RLHF o DPO; el esquema profesor-juez sugiere evaluacion y filtrado mas que optimizacion por preferencias. Los detalles de revisiones fijadas, seleccion de datos y versiones de runtime estan en `provenance.json`, y los resultados en `metrics/summary.json` y `metrics/report.md`.

## Capacidades

- Adaptacion de comportamiento de asistente: los LoRA estan pensados para modular el estilo y las preferencias de respuesta de los modelos base, no para anadir conocimiento nuevo.
- Transferencia entre modelos: el experimento proyecta comportamiento desde Mistral-7B hacia Llama-3.1-8B, lo que permite estudiar la portabilidad de adaptadores entre familias.
- Evaluacion con juez automatico: el pipeline usa Qwen3-14B como juez, lo que habilita comparaciones cuantitativas de respuestas generadas.
- Interpretabilidad: los artefactos incluyen respuestas evaluadas y registros de tiempos para auditar el efecto de la proyeccion de pesos.
- No se documentan capacidades de tool calling, function calling, agentes, vision, audio ni modo thinking.
- Capacidades multilingues: no disponibles.

## Casos de uso

- Investigacion en transferencia de comportamiento: usar los adaptadores para estudiar si las preferencias aprendidas en Mistral-7B se conservan al proyectarlas sobre Llama-3.1-8B, comparando respuestas con el juez Qwen3-14B.
- Auditoria de tecnicas de proyeccion de pesos: reproducir el pipeline descrito en `provenance.json` para validar la metodologia con revisiones fijadas y versiones de runtime concretas.
- Analisis de personalizacion sin memorizacion factica: emplear el conjunto para examinar como se modula el estilo del asistente sin introducir datos biograficos, util en estudios de privacidad.
- Evaluacion con jueces automaticos: reutilizar las respuestas y los registros de tiempos para calibrar la fiabilidad de Qwen3-14B como juez en tareas de preferencia.
- Docencia y formacion: ilustrar en cursos de interpretabilidad como se construye y evalua un adaptador LoRA con modelos profesor y juez separados.
- Base para experimentos propios: partir de estos adaptadores como referencia para entrenar LoRA sobre otros pares de modelos, manteniendo la atribucion de Dolly y PersonaAtlas.
