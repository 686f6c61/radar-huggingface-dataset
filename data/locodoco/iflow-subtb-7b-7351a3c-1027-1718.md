# locodoco/iflow-subtb-7b-7351a3c-1027-1718

## Resumen

`locodoco/iflow-subtb-7b-7351a3c-1027-1718` es un archivo de experimentos (model archive) publicado en Hugging Face por el usuario `locodoco`. No se trata de un modelo entrenado y publicado como producto final, sino de una colección de checkpoints intermedios de un experimento denominado `iflow_original`, orientado a la resolución de problemas matemáticos mediante trayectorias de razonamiento multi-turno. El identificador del repositorio sugiere un modelo de aproximadamente 7.000 millones de parámetros, aunque la model card no confirma explícitamente el recuento.

El repositorio contiene 17 checkpoints guardados en subcarpetas `global_step_N/` (pasos 25, 50, 75, 100, 125, 150, 175, 200, 225, 250, 275, 300, 325, 350, 375, 400 y 425), cada una con los pesos en formato Hugging Face y los ficheros de tokenizador y configuración asociados. El tamaño del repositorio es de 28,4 GB, coherente con múltiples copias de pesos de un modelo de escala 7B en precisión de 16 bits.

La relevancia de este repositorio es limitada para uso en producción: se trata de material de investigación que solo permite generar respuestas y analizar trayectorias de resolución de problemas guardadas, y requiere el código original del controlador/solver multi-turno, los prompts y los ajustes de generación para reproducir los experimentos. No se publican resultados de benchmarks ni detalles sobre la arquitectura o los datos de entrenamiento.
