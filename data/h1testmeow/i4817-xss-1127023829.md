No hay arquitectura de red neuronal ni proceso de entrenamiento. ## Casos de uso

- Auditoria de sanitizadores Markdown: cargar el README en un visor y comprobar si alguna asignacion `window.__N*` se ejecuta, lo que revelaria un fallo de saneamiento.
- Pruebas de regresion en plataformas de model cards: usar los payloads como corpus de entrada para validar que el renderizador escapa correctamente entidades y contextos SVG/MathML.
- Formacion en seguridad ofensiva: ilustrar tecnicas de ofuscacion de esquemas `javascript:` mediante entidades numericas y hexadecimales.
- Evaluacion de Content Security Policy: verificar que una CSP estricta bloquea la ejecucion incluso si el HTML se inyecta sin escapar.
- Investigacion de bug bounty: reproducir la sonda `i4817` como parte de una serie para reportar vulnerabilidades a Hugging Face.
- Desarrollo de librerias de saneamiento (DOMPurify, bleach): incorporar estos vectores como casos de test en la suite de la libreria.

Ninguno de estos casos implica ejecutar inferencia; son escenarios de seguridad web.
