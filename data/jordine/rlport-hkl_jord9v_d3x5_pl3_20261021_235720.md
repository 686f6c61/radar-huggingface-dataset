# Jordine/rlport-hkl_jord9v_d3x5_pl3_20261021_235720

## Resumen

`Jordine/rlport-hkl_jord9v_d3x5_pl3_20261021_235720` no es un modelo publicado, sino una copia de seguridad automática de un checkpoint de entrenamiento por refuerzo. Según la propia model card, el repositorio contiene adaptadores LoRA (etiquetados como Qwen3.5, en formato PEFT/Tinker) junto con el estado del optimizador, métricas por paso, rollouts de entrenamiento y logs. El autor lo describe explícitamente como «research artifact only; not a model release, not intended for use».

El artefacto procede del proyecto denominado "reward-laundering" y fue generado por el script `scripts/port/hf_backup.py` para permitir reanudar una ejecución de RL cuando la máquina con GPU en la nube desaparezca (port desde Tinker hacia vast). Es, por tanto, infraestructura de recuperación de experimentos, no un peso listo para inferencia.

Su relevancia es documental: sirve para estudiar cómo se versionan y respaldan ejecuciones de RL sobre modelos grandes (adaptadores + estado del optimizador + trayectorias) fuera de la máquina de entrenamiento. No hay información pública sobre arquitectura del modelo base, número de parámetros, contexto, licencia ni idiomas, y el repositorio no incluye pipeline de inferencia.
