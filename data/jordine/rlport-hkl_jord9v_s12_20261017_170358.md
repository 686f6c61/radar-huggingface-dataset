# Jordine/rlport-hkl_jord9v_s12_20261017_170358

## Resumen

`Jordine/rlport-hkl_jord9v_s12_20261017_170358` no es un modelo publicado, sino un artefacto de investigación: una copia de seguridad automática de un único run de entrenamiento por refuerzo (RL) perteneciente al proyecto denominado "reward-laundering". El autor lo describe explícitamente como "research artifact only; not a model release, not intended for use". El repositorio contiene adaptadores LoRA (con layout PEFT/Tinker) sobre una base identificada como Qwen3.5, junto con el estado del optimizador, métricas por paso, rollouts de entrenamiento y logs.

El contenido se generó mediante el script `scripts/port/hf_backup.py` en un flujo de portabilidad desde Tinker hacia una máquina GPU en vast, con el objetivo de poder reanudar el run si la instancia cloud desaparece. El repositorio pesa 1,1 GB y se creó el 17 de octubre de 2026, con una actualización siete minutos posterior.

Por su naturaleza, no dispone de pipeline, licencia declarada, idiomas documentados ni resultados de evaluación. Cualquier uso previsto pasa por la auditoría, la reproducibilidad o la reanudación del entrenamiento, no por la inferencia en producción.
