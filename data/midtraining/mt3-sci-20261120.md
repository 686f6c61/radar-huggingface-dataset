# midtraining/mt3-sci-20261120

## Resumen

`mt3-sci-20261120` es un repositorio de artefactos de entrenamiento publicado por el usuario `midtraining` en Hugging Face. No se trata de un modelo con pesos listos para inferencia, sino de un paquete de scripts y configuraciones que complementa a un paquete anterior denominado `mt3-ladder-20261113`. El contenido descrito en la model card son tareas de entrenamiento (denominadas SCI) sobre el modelo base Qwen3-1.7B-Base, con un presupuesto de 8B tokens por tarea.

Segun la model card, el repositorio contiene unicamente la carpeta `sci_sota/`, que se descarga sobre el arbol de directorios del paquete `mt3-ladder-20261113` y anade dos tareas formales: una de "doble vista" y otra de "vista alterna", cada una configurada para ejecutarse en 8 GPUs con 8 procesos. Posteriormente se anadio una tercera tarea (vista alterna con multiples formulaciones), tambien para 8 GPUs. El tamano del repositorio (0,6 GB) es coherente con un conjunto de scripts y ficheros de configuracion, no con pesos de un modelo de 1.700 millones de parametros en precision completa.

La relevancia de este repositorio es limitada para el publico general: es material de trabajo interno de un proyecto de investigacion sobre metodos de entrenamiento (SCI) aplicados a un modelo base concreto. No hay pipeline declarado, ni licencia, ni idiomas, ni resultados de evaluacion publicados en la informacion disponible. Cualquier uso en produccion requeriria obtener por separado el modelo base y el paquete `mt3-ladder-20261113`, ademas de verificar los terminos de uso de ambos.

## Casos de uso

- Reproduccion de experimentos de investigacion: el repositorio permite replicar las tareas SCI sobre Qwen3-1.7B-Base siguiendo las instrucciones de `sci_sota/README.md`, siempre que se disponga del paquete `mt3-ladder-20261113` y de 8 GPUs.
- Extension de un pipeline de entrenamiento existente: el script `add_sci_job.py` genera dos tareas y las coloca al frente de la cola de trabajos, lo que facilita anadir experimentos a un flujo ya montado sin volver a descargar codigo ni datos.
- Comparacion de variantes de vista (doble vista frente a vista alterna): util para estudiar el efecto de distintas formulaciones de la tarea sobre el mismo modelo base y el mismo presupuesto de tokens.
- Evaluacion de metodos de midtraining: el nombre del autor (`midtraining`) y la estructura de tareas sugieren un uso orientado a estudiar fases intermedias de entrenamiento; el repositorio serviria como base para medir su impacto.
- Auditoria de artefactos de entrenamiento: al contener solo scripts y configuraciones, permite revisar como se lanzan los trabajos, que recursos consumen y como se organizan las tareas antes de ejecutarlas en un cluster.
- Integracion en un sistema de gestion de colas: el modo `--print` del script permite previsualizar los trabajos generados antes de encolarlos, lo que encaja en entornos con planificacion de recursos compartidos.
