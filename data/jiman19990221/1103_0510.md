## Capacidades

- Orquestacion de agentes de programacion con edicion coordinada de multiples archivos en un proyecto.
- Ejecucion de comandos de terminal con lectura de salida en tiempo real, incluyendo procesos de larga duracion como servidores de desarrollo.
- Monitorizacion de errores de linter y compilador para corregir importaciones ausentes, desajustes de tipos y errores de sintaxis.
- Modos Plan y Act con aprobacion humana de cada edicion y comando, o modo auto-aprobado para ejecucion autonoma.
- Sistema de checkpoints para revertir cambios del agente.
- Reglas de proyecto en archivos `.clinerules` y mecanismo de skills para carga selectiva de reglas.
- Soporte de multiples proveedores de modelos: Anthropic, OpenAI, Google, OpenRouter, Vercel AI Gateway, AWS Bedrock, Azure, GCP Vertex, Cerebras y Groq.
- Integracion con servidores MCP (Model Context Protocol) y plugins.
- SDK programatico en Node.js para construir agentes propios, equipos multiagente y automatizaciones programadas.

## Casos de uso

- Refactorizacion multiarchivo en un repositorio real: Cline lee la estructura del proyecto, identifica dependencias entre ficheros y aplica cambios coordinados mostrando cada modificacion como un diff revisable, lo que encaja en equipos que exigen revision humana antes de commit.
- Correccion automatica de errores de compilacion: el agente ejecuta el build, interpreta los errores del compilador y aplica parches iterativos hasta que el pipeline pasa, usando el modo Act con auto-aprobacion controlada.
- Automatizacion en CI/CD: la CLI permite ejecucion headless para lanzar tareas de agente en pipelines, por ejemplo generacion de tests o aplicacion de migraciones de codigo con validacion posterior.
- Asistencia en el IDE para desarrolladores: la extension de VS Code y el plugin de JetBrains ofrecen chat interactivo con acceso al arbol de ficheros, ejecucion de comandos y navegacion web dentro del editor.
- Gestion de tareas programadas en escritorio: la aplicacion nativa para macOS y Windows permite programar rutinas de agente sobre carpetas concretas, util para tareas periodicas de mantenimiento de codigo o generacion de informes.
- Construccion de agentes personalizados: el SDK `@cline/sdk` permite integrar el motor de agente en productos propios con herramientas personalizadas, conectores y equipos multiagente.
- Estandarizacion de convenciones de equipo: los archivos `.clinerules` permiten fijar estandares de codigo, convenciones de arquitectura y procedimientos de despliegue que el agente aplica de forma consistente en CLI, VS Code y JetBrains.
