# mailsdaddysoftware/pst-file-converter

## Resumen

El repositorio `mailsdaddysoftware/pst-file-converter` en Hugging Face no contiene un modelo de inteligencia artificial, sino un enlace a un producto software comercial: MailsDaddy PST File Converter, desarrollado por la empresa MailsDaddy. Se trata de una utilidad para Windows que permite convertir archivos PST de Outlook (tanto ANSI como Unicode, e incluso dañados) a otros formatos de correo como MBOX, EML, MSG, HTML, PDF, MHTML y RTF.

Aunque el repositorio está alojado en una plataforma orientada a modelos de IA, su contenido se limita a una descripción del software y enlaces externos. No se proporciona ningún artefacto de modelo, pesos, arquitectura ni documentación técnica relacionada con IA. Por tanto, cualquier especificación habitual de un modelo (parámetros, contexto, licencia de modelo, etc.) no está disponible o no aplica.

La relevancia de esta ficha es aclarar que no se trata de un modelo de IA y evitar confusiones a desarrolladores que buscan modelos de procesamiento de lenguaje natural. El software puede ser útil para migraciones de correo, pero no ofrece capacidades de IA generativa ni de razonamiento.

## Arquitectura y entrenamiento

No aplica. Este repositorio no contiene un modelo de IA, por lo que no existe arquitectura de red neuronal, datos de entrenamiento, ni procesos de RLHF o DPO. El software MailsDaddy PST File Converter es una aplicacion nativa de Windows que utiliza tecnicas de analisis y extraccion de datos de archivos PST de Outlook, pero no se documenta ningun componente de aprendizaje automatico en la informacion proporcionada.

## Capacidades

- Conversion de archivos PST de Outlook a formatos MBOX, EML, MSG, HTML, PDF, MHTML y RTF.
- Soporte para archivos PST ANSI y Unicode.
- Capacidad para procesar archivos PST corruptos o danados, extrayendo datos accesibles.
- Conversion por lotes, exportacion selectiva de carpetas o correos, y filtros de conversion segun criterios del usuario.
- Exportacion de contactos a VCF y calendarios a ICS (segun la pagina web oficial).
- Compatible con Windows 11 y Windows 10.
- Edicion de prueba "Evolution Edition" para evaluar el software antes de comprar la version completa.

No se incluyen capacidades de generacion de texto, razonamiento, codigo, vision, tool calling, agentes ni funciones de IA.

## Casos de uso

- Migracion de correo de Outlook a Thunderbird: el software convierte PST a MBOX, el formato nativo de Thunderbird, facilitando la importacion de buzones completos.
- Archivado de correos en PDF: permite generar copias de seguridad legibles y portables de correos individuales o carpetas enteras en formato PDF.
- Extraccion de contactos y calendarios: exporta contactos a VCF y calendarios a ICS para importarlos en otras aplicaciones de gestion de contactos o calendarios.
- Recuperacion de datos de PST danados: cuando un archivo PST esta corrupto, la herramienta puede extraer los datos accesibles y convertirlos a formatos estandar, evitando la perdida total de informacion.
- Migracion parcial: el usuario puede seleccionar solo ciertas carpetas o correos para convertir, reduciendo el tiempo de procesamiento en migraciones grandes.
- Integracion en flujos de trabajo de soporte tecnico: los administradores de sistemas pueden usar la herramienta para convertir buzones de usuarios que cambian de plataforma de correo, sin necesidad de instalar Outlook.
