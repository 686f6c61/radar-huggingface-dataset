# CladeTeam/CENO-600M-131k

## Resumen

CENO-600M-131k es un checkpoint de contexto largo del modelo fundacional de ADN CENO, desarrollado por CladeTeam. Se trata de un modelo de lenguaje causal sobre secuencia genómica construido sobre una arquitectura híbrida Nemotron-H que combina capas Mamba, atención y mezcla de expertos (MoE), sin entradas de alineamiento múltiple de secuencias (MSA). Con 630,8 millones de parámetros en precisión bfloat16, este checkpoint corresponde a la tercera etapa de entrenamiento del modelo base, la extensión de contexto, y fue entrenado con secuencias de 131.072 tokens.

El modelo resuelve el problema de modelar secuencias genómicas de forma generativa y extraer representaciones útiles para tareas de genómica, como la generación de secuencias de ADN y la adaptación posterior mediante fine-tuning o probing. Su tokenizador a nivel de carácter mapea cada base de ADN a su código ASCII de byte, con un vocabulario de solo 512 entradas, lo que evita dependencias de vocabularios naturales y mantiene una correspondencia directa entre token y nucleótido.

Es relevante ahora porque los modelos fundacionales de genómica están pasando de arquitecturas transformer puras a híbridos eficientes en contexto largo, y CENO adopta explícitamente el backbone Nemotron-H de NVIDIA con licencia Apache-2.0. La familia CENO incluye además checkpoints con MSA (CENO-P-*) orientados a la predicción de efectos de variantes (VEP) mediante el cálculo de diferencias de log-verosimilitud entre secuencia silvestre y variante.

## Arquitectura y entrenamiento

El backbone es un híbrido Nemotron-H con 20 capas ocultas, tamaño oculto de 1024, 16 cabezas de atención e intermediate size de 4096. Incorpora una capa MoE con 8 expertos y enrutamiento top-2 por token. El tokenizador es de nivel de carácter, derivado del CharLevelTokenizer de Evo2 (Arc Institute), y mapea las bases de ADN a sus códigos ASCII de byte con un vocabulario de 512 entradas. Este checkpoint corresponde a la etapa 3 de entrenamiento del modelo base CENO, dedicada a la extensión de contexto hasta 131.072 tokens.

No se especifican en la información disponible el número total de tokens de entrenamiento, la composición del dataset genómico ni si se aplicaron etapas de RLHF o DPO. La model card indica que las capas Mamba requieren kernels CUDA, por lo que las pasadas forward y la generación necesitan GPU, mientras que la carga de configuración, tokenizador y pesos es segura en CPU. El stack probado es PyTorch 2.7.0a0 (NVIDIA 25.03), Transformers 4.48.3, mamba-ssm 2.2.4, causal-conv1d 1.2.2.post1 y FlashAttention 2.7.3.

## Capacidades

- Generación de secuencias genómicas de ADN mediante modelado de lenguaje causal a nivel de carácter.
- Extracción de embeddings de secuencia para tareas downstream de genómica.
- Adaptación mediante fine-tuning y probing para tareas genómicas específicas.
- Procesamiento de contexto muy largo (hasta 131.072 tokens por prefill en la ruta HF; el repositorio ofrece una entrada vLLM para prefills mayores).
- Soporte de scoring de verosimilitud para comparación de secuencias (base para VEP en los checkpoints CENO-P-*).
- No dispone de soporte documentado de tool calling, function calling, agentes, visión, audio ni modo thinking.
- Capacidades multilingües de lenguaje natural: no aplicables; el modelo opera sobre alfabeto de nucleótidos.

## Casos de uso

- Generación de secuencias de ADN sintéticas: el modelo puede muestrear secuencias nucleotídicas verosímiles a partir de un prefijo, útil para aumentar datasets genómicos o explorar regiones de secuencia plausibles en investigación.
- Extracción de embeddings para clasificación genómica: se pueden obtener representaciones de ventanas largas de ADN y entrenar cabezas de clasificación para tareas como identificación de regiones regulatorias o elementos funcionales.
- Predicción de efectos de variantes: aunque esta tarea se asocia a los checkpoints CENO-P-*, el modelo base permite puntuar secuencias silvestres frente a variantes mediante delta de log-verosimilitud, integrable en pipelines de VEP.
- Fine-tuning para tareas genómicas específicas: al ser un checkpoint base, sirve como punto de partida para adaptar el modelo a organismos o familias génicas concretas con datasets propios.
- Análisis de contexto largo en genómica: con 131.072 tokens de entrenamiento y ausencia de ventana fija, permite modelar regiones genómicas extensas de una sola pasada, útil para estudios de estructura y dependencias de largo alcance.
- Investigación en modelos híbridos Mamba/MoE: su arquitectura Nemotron-H lo hace adecuado como banco de pruebas para estudiar eficiencia y calidad en dominios no textuales.

## Requisitos de hardware

- Inferencia en bfloat16: 630,8M parámetros implican aproximadamente 1,3 GB de pesos, más estados de activación y caché de secuencia; se recomienda GPU con al menos 8-16 GB de VRAM para contextos moderados.
- Las capas Mamba requieren kernels CUDA (mamba-ssm, causal-conv1d), por lo que la inferencia no es viable en CPU.
- GPU recomendadas: cualquier GPU CUDA moderna; el stack probado emplea FlashAttention 2.7.3, lo que favorece GPUs Ampere o superiores (A100, H100, RTX 3090/4090).
- Cabe en GPUs de consumo como RTX 3090 o RTX 4090 para contextos cortos o medios; para prefills de 131.072 tokens se requiere mayor VRAM.
- Opciones de despliegue: transformers con trust_remote_code=True (single-GPU, máximo 131.072 tokens por prefill) y la entrada vLLM del repositorio CENO para prefills mayores.
- Latencia y throughput: no disponibles en la información proporcionada.

## Limitaciones y advertencias

- La corrección numérica de la implementación no garantiza generación libre de repeticiones ni biológicamente funcional; las secuencias generadas no deben interpretarse como válidas sin validación experimental.
- El modelo es un checkpoint base: no está ajustado para instrucciones ni para tareas concretas sin adaptación previa.
- Las capas Mamba exigen CUDA; no hay ruta de inferencia en CPU documentada.
- La ruta HF de precisión es single-GPU, sin padding y limitada a 131.072 tokens por prefill; prefills mayores requieren vLLM.
- Las referencias de precisión BF16 bit a bit no cubren CPU, FP32 explícito ni atención eager; las referencias de Megatron CP no son intercambiables entre configuraciones.
- La evidencia de contexto de 1M pertenece a CENO-1B-1m, no a este checkpoint.
- No se documentan sesgos, riesgos de alucinación en sentido lingüístico ni limitaciones idiomáticas aplicables, al operar sobre secuencia genómica.
- Licencia Apache-2.0 permite uso comercial, con obligación de mantener atribuciones del código de NVIDIA Nemotron-H y del tokenizador de Evo2 según los ficheros LICENSE y NOTICE.
