# e54true/deeptable-checkpoints-qwen25-7b

## Resumen

DeepTable es una colección de 64 adaptadores LoRA entrenados sobre el modelo base Qwen2.5-7B-Instruct para tareas de comprensión jerárquica de tablas. Desarrollado por e54true, implementa las técnicas presentadas en el paper "DeepTable: Structural Attention Biases and Tree Path Encoding for Hierarchical Table Understanding". El repositorio contiene los checkpoints correspondientes a la Tabla 2 del paper: la línea base TableLoRA, las variantes con solo sesgos de atención estructural (SAB), solo codificación de rutas de árbol (TPE) y la combinación
