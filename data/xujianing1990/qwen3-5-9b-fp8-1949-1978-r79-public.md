# xujianing1990/qwen3.5-9b-fp8-1949-1978-r79-public

## Resumen

El modelo `xujianing1990/qwen3.5-9b-fp8-1949-1978-r79-public` es un derivado del modelo base Qwen/Qwen3.5-9B publicado por el usuario xujianing1990 en HuggingFace. Se trata de un adaptador LoRA fusionado con el modelo base y cuantizado en FP8 mediante la librería `compressed-tensors`, empaquetado en formato safetensors para su uso con transformers y vLLM. El nombre del repositorio sugiere una configuración de entrenamiento concreta (posiblemente épocas o pasos identificados como "1949-1978-r79"), aunque no se dispone de documentación que lo confirme.

El modelo está orientado a tareas de generación de texto e image-text-to-text, lo que indica que hereda las capacidades multimodales del Qwen3.5-9B original. Con 9.653.104.368 parámetros totales y un tamaño de repositorio de 12,2 GB, es un modelo de escala media que puede desplegarse en GPUs de gama alta para consumo o en entornos de servidor con múltiples GPUs consumer. La cuantización FP8 reduce el peso en memoria respecto a BF16/FP16, lo que facilita su despliegue en infraestructura más modesta.

La relevancia de este modelo es limitada y específica: al ser un derivado no oficial con solo 17 descargas y sin documentación técnica publicada, su interés principal radica en servir como ejemplo de pipeline de cuantización FP8 con `compressed-tensors` y vLLM, o como base para experimentación con adaptadores LoRA sobre Qwen3.5-9B. No debe confundirse con una versión oficial de Qwen, y su acceso está restringido (gated), requiriendo aceptar condiciones en HuggingFace.

## Arquitectura y entrenamiento

La arquitectura subyacente corresponde a Qwen3.5-9B, un transformer de la familia Qwen 3.5 desarrollada por Alibaba. El repositorio incluye la etiqueta `qwen3_5`, `image-text-to-text` y `mtp` (multi-token prediction), lo que sugiere que el modelo base incorpora capacidades multimodales y posiblemente decodificación especulativa mediante predicción multi-token. Sin embargo, no se dispone de información detallada sobre el número de capas, dimensión oculta, número de cabezas de atención ni composición del dataset de entrenamiento del modelo base.

El proceso de creación de este derivado combina un adaptador LoRA (etiqueta `lora` y `base_model:adapter:Qwen/Qwen3.5-9B`) fusionado con el modelo base, seguido de una cuantización FP8 mediante `compressed-tensors`. El nombre del repositorio (`1949-1978-r79`) sugiere un checkpoint intermedio de un entrenamiento, pero no hay documentación que confirme el número de tokens de entrenamiento, la composición del dataset ni si se aplicaron técnicas de RLHF o DPO. La etiqueta `endpoints_compatible` indica compatibilidad con endpoints de inferencia, presumiblemente vLLM.
