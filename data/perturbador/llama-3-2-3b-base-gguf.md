# Perturbador/llama-3.2-3b-base-gguf

## Resumen

Este repositorio contiene una conversión a GGUF de un ajuste fino del modelo Llama 3.2 3B base, publicado por el usuario Perturbador. El modelo tiene 3.212.749.888 parámetros y se distribuye en un único archivo cuantizado Q4_K_M dentro de un repositorio de 2,0 GB. La model card indica que el ajuste fino y la conversión se realizaron con Unsloth, y que el formato está pensado para su uso con llama.cpp.
