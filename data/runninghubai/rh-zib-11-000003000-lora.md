## Arquitectura y entrenamiento

El objeto publicado es un adaptador LoRA (Low-Rank Adaptation): un conjunto de matrices de bajo rango que se inyectan en las capas del modelo base para desplazar su comportamiento hacia un concepto, sujeto o estilo concreto, manteniendo congelados los pesos originales. Esta tecnica reduce el coste de ajuste fino y el tamano del artefacto resultante; en este caso, el fichero final ocupa 81 MiB, un orden de magnitud coherente con un adaptador de rango moderado y no con un ajuste completo del modelo.

La model card no aporta informacion sobre el dataset de entrenamiento, el numero de imagenes o de pasos, el rango del adaptador, la tasa de aprendizaje, el uso de regularizacion o el posible empleo de tecnicas de alineacion (RLHF, DPO o similares), conceptos que en generacion de imagenes se sustituyen habitualmente por ajuste por preferencias humanas o filtrado de datos. Tampoco se detalla si el ajuste se realizo sobre un transformer de difusion, un UNet o una arquitectura hibrida, ni la identidad exacta del modelo Z-image-base. No se documenta ninguna innovacion tecnica adicional (decodificacion especulativa, atencion lineal, muestreo destilado, etc.).

- Generacion de personajes consistentes para ilustracion editorial: el adaptador permite fijar un mismo sujeto en varias ilustraciones de una serie, manteniendo una apariencia estable entre escenas siempre que se use el mismo prompt base y las mismas semillas de referencia.

- Fotografia de producto o moda con modelos virtuales: generacion de imagenes de catalogo donde el sujeto debe ser coherente entre tomas, evitando sesiones fotograficas completas en fases de validacion de concepto.
- Automatizacion por API en produccion por lotes: la model card enlaza la API de RunningHub y la plataforma de entrenamiento, lo que permite invocar el LoRA como servicio y generar imagenes de forma programatica sin mantener GPU propia.

- Generacion de variaciones de estilo dentro de una campana: combinado con cambios de prompt y con otros adaptadores en la misma cadena de ComfyUI, permite explorar variaciones visuales manteniendo la identidad del sujeto.
