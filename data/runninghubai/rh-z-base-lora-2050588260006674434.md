# RunningHubAI/rh-z-base-lora-2050588260006674434

## Resumen

`rh-z-base-lora` es un adaptador LoRA para generación de imágenes a partir de texto (text-to-image), publicado por el usuario RunningHubAI en Hugging Face y entrenado sobre el modelo base Z-image-base. El adaptador está orientado a un tema muy concreto: el personaje Han Li (韩立) de la obra *Mortal Cultivation Biography* (Una vita inmortal / A Record of a Mortal's Journey to Immortality), tal como se deduce del nombre del fichero de pesos (`韩立Z-base.safetensors`) y de la descripción de la model card.

No se trata de un modelo fundacional autónomo, sino de un conjunto de pesos de bajo rango (LoRA) de aproximadamente 76 MiB que debe cargarse junto con el modelo base Z-image-base dentro de ComfyUI, la plataforma RunningHub o Hugging Face. Su utilidad, por tanto, depende por completo del modelo subyacente y del pipeline de difusión en el que se integre.

El repositorio es de creación muy reciente (noviembre de 2026) y, en el momento de la consulta, no registra descargas ni interacciones. La información técnica disponible es escasa: la model card no detalla hiperparámetros de entrenamiento, dataset, resolución nativa ni condiciones de licencia más allá de una remisión genérica a la licencia del proyecto original.

## Arquitectura y entrenamiento

El artefacto publicado es un adaptador LoRA, es decir, un conjunto de matrices de bajo rango que se inyectan en las capas del modelo base Z-image-base para especializar su comportamiento hacia un concepto visual concreto (el personaje Han Li). La model card no especifica la arquitectura del modelo base, el número de pasos de entrenamiento, la resolución de las imágenes de entrenamiento, el tamaño del dataset ni si se emplearon técnicas como regularización por clase, captions específicos o entrenamiento con DreamBooth.

Tampoco se documentan hiperparámetros del LoRA (rango, alpha, tasa de aprendizaje, optimizador) ni el pipeline de muestreo recomendado. El único dato técnico verificable es el tamaño del fichero de pesos (~76 MiB) y el modelo de procedencia (Z-image-base). No se indica si el adaptador fue entrenado mediante el servicio de entrenamiento de RunningHub, aunque la model card enlaza a esa plataforma.
