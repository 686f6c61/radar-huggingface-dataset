# RunningHubAI/rh-illustrious-lora-2100149858362736642

## Resumen

`rh-illustrious-lora` es un adaptador LoRA (Low-Rank Adaptation) para generacion de imagenes con modelos de difusion de la familia Illustrious XL (IL-XL), especializados en ilustracion anime. Lo publica RunningHubAI, la cuenta de la plataforma RunningHub, que aloja pesos de terceros entrenados por sus usuarios; en este caso el autor acreditado es `@kucha`. El repositorio contiene un unico fichero de pesos de 218 MiB (`锁暝.safetensors`) y no incluye pipeline, licencia ni idiomas declarados en los metadatos de Hugging Face.

El modelo no es un modelo de lenguaje ni un checkpoint completo: es un modulo complementario que se carga sobre un checkpoint base de Illustrious XL para inyectar un estilo o concepto concreto. La model card recomienda combinarlo con el checkpoint KC-Illustrious Anime Texture y ofrece parametros de inferencia tipicos de Stable Diffusion (peso 0.7-0.8, CFG 5, 25-30 pasos, sampler Euler, resolucion 768x1024).

Su relevancia es acotada: interesa a quien construye flujos de generacion de imagenes en ComfyUI y quiere reproducir un estilo concreto de la plataforma RunningHub sin depender del servicio en la nube. La informacion publica es muy escasa, por lo que buena parte de las especificaciones habituales quedan como no disponibles.

## Arquitectura y entrenamiento

El artefacto es un adaptador LoRA, es decir, un conjunto de matrices de bajo rango que se suman a las proyecciones de atencion y/o capas lineales del modelo base. Se aplica sobre un checkpoint de la familia Illustrious XL, un derivado de Stable Diffusion XL ajustado para ilustracion anime. La model card indica explicitamente "Finetuned from: IL-XL", pero no detalla en que modulos se insertan las matrices, el rango utilizado ni el factor alpha.

No se publica informacion sobre el dataset de entrenamiento: ni numero de imagenes, ni composicion, ni resolucion, ni si hubo tecnicas de regularizacion o captioning. Tampoco se documenta el proceso de entrenamiento (pasos, learning rate, hardware). La unica informacion operativa es la recomendacion de uso: peso entre 0.7 y 0.8, CFG 5, entre 25 y 30 pasos de muestreo, sampler Euler y resolucion de 768x1024, junto con el checkpoint base sugerido (KC-Illustrious Anime Texture).

## Capacidades

- Generacion de imagenes de ilustracion estilo anime mediante difusion latente, condicionada por texto, sobre un checkpoint Illustrious XL.
- Inyeccion de un estilo o concepto visual concreto aprendido por el LoRA, ajustable mediante el peso del adaptador (0.7-0.8 recomendado).
- Compatibilidad con flujos de ComfyUI, segun las etiquetas del repositorio.
- Uso conjunto con el checkpoint KC-Illustrious Anime Texture, recomendado por el autor.
- Integracion en la plataforma RunningHub, tanto en su interfaz como via API.
- No soporta tool calling, agentes, razonamiento multi-paso, vision de entrada ni audio: es un modelo puramente generativo de imagen.

## Casos de uso

- Ilustracion anime por encargo: cargar el LoRA sobre Illustrious XL en ComfyUI con peso 0.7-0.8 y generar imagenes a 768x1024 con CFG 5 y Euler, para producir ilustraciones de personaje con el estilo del adaptador.
- Prototipado de estilos en estudio: comparar el LoRA a distintos pesos (0.6, 0.7, 0.8) sobre el mismo prompt y semilla para calibrar la intensidad del estilo antes de fijar un pipeline de produccion.
- Generacion por lotes de assets para juegos o publicaciones: automatizar la creacion de variaciones de personaje con un script que invoque ComfyUI o la API de RunningHub, manteniendo parametros fijos de muestreo.
- Reproduccion local de un flujo alojado en RunningHub: descargar el LoRA y el checkpoint KC-Illustrious Anime Texture para ejecutar en local el mismo flujo que la plataforma ofrece en linea, evitando dependencia de la nube.
- Exploracion de prompts para text-to-image: usar el adaptador como capa de estilo sobre un checkpoint IL-XL y evaluar como responde a variaciones de prompt, CFG y sampler.
- Integracion en productos creativos: exponer la generacion mediante la API de RunningHub en una aplicacion de edicion o generacion de imagenes, usando el LoRA como preset de estilo.
