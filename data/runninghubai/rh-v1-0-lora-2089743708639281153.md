# RunningHubAI/rh-v1.0-lora-2089743708639281153

## Resumen

rh-v1.0-lora es un adaptador LoRA de tipo text-to-image publicado en Hugging Face por RunningHubAI, la cuenta oficial de la plataforma RunningHub. No se trata de un modelo base autonomo, sino de un conjunto de pesos de ajuste fino (316 MiB en un unico fichero safetensors) que se aplica sobre el modelo Flux2-Klein-9B para especializarlo en la generacion de un personaje concreto: Liu Shen, de la obra de animacion china *Perfect World*, en su version teatral "Nine Tribulations Burning Heaven" (primer conjunto, V1.0).

El adaptador esta pensado para su uso dentro de ComfyUI o en la propia plataforma RunningHub, y su unico proposito es el de un character LoRA: reproducir de forma consistente el diseno visual del personaje cuando se activa mediante la palabra disparadora `liushen_fzjjft1`. No aporta capacidades nuevas de razonamiento ni de generacion de texto; su relevancia es la de un recurso artistico especializado dentro del ecosistema de generacion de imagenes con Flux.

Dado que se publica como LoRA sobre un modelo de difusion, sus especificaciones tecnicas dependen en gran medida del modelo base (Flux2-Klein-9B), del que la model card no detalla parametros, contexto ni licencia. La informacion disponible sobre el adaptador en si es minima: tipo, tamano del fichero, modelo de origen y trigger word.

## Arquitectura y entrenamiento

El artefacto es un LoRA, es decir, un conjunto de matrices de bajo rango que se inyectan en las capas del modelo base para modificar su comportamiento sin reentrenar todos los pesos. En este caso el modelo base es Flux2-Klein-9B, un modelo de difusion texto-a-imagen de la familia Flux, segun indica la model card en el campo "Finetuned from". El fichero entregado contiene unicamente los pesos del adaptador; no se incluye el modelo base ni se documentan los hiperparametros de entrenamiento (rango, alpha, learning rate, numero de pasos, dataset utilizado).

No se dispone de informacion sobre el volumen de imagenes de entrenamiento, la composicion del dataset, el uso de regularizacion o tecnicas de captions, ni sobre si se aplicaron procesos de RLHF o DPO (no aplicables de forma habitual en difusion, pero no confirmados). Tampoco se documenta ninguna innovacion tecnica adicional mas alla del ajuste fino sobre Flux2-Klein-9B. La unica indicacion operativa es la trigger word `liushen_fzjjft1`, que debe incluirse en el prompt para activar el estilo y el personaje aprendidos.

- Ilustracion de fan art de *Perfect World*: el LoRA permite generar imagenes del personaje Liu Shen en la version teatral con un estilo coherente, usando la trigger word junto a la descripcion de escena en el prompt, lo que resulta adecuado para creadores que necesitan consistencia visual del personaje.

- Uso via API de RunningHub: equipos que no quieran gestionar infraestructura GPU pueden invocar el modelo alojado a traves de la API de la plataforma, util para integrar generacion de imagenes en aplicaciones web o bots.

- Sesgos conocidos: no documentados; al entrenarse sobre un personaje de una obra concreta, puede reproducir el estilo y las caracteristicas del diseno original, con el riesgo de sobreajuste a poses o composiciones del dataset de entrenamiento.
