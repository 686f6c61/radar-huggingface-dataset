# RunningHubAI/rh-qwen-image-2.1-lora-2104918997757157378

## Resumen

rh-qwen-image-2.1-lora es un adaptador LoRA de generacion de imagenes (text-to-image) publicado por RunningHubAI en Hugging Face. No es un modelo completo: es un ajuste fino de bajo rango que se aplica sobre el modelo base qwen-image-2.1 y que anade un efecto muy concreto de iluminacion y composicion fotografica. Segun la model card, su proposito es aplicar una iluminacion coherente a un producto u objeto, reforzar los brillos especulares, respetar la relacion espacial delante-detras, anadir una sombra de contacto natural y fundir el objeto con el fondo de forma continua.

El repositorio contiene un unico archivo de pesos, `Qwenimag21_c2-st2000.safetensors`, de 160 MiB, entrenado hasta 2000 pasos (indicado en el propio nombre del archivo). La activacion del efecto se realiza mediante la palabra disparadora `pengyu`, que debe colocarse al principio del prompt segun las instrucciones del autor.

La relevancia de esta ficha es acotada pero util: se trata de un ejemplo tipico de LoRA verticalizado para pipelines de ComfyUI y de la plataforma RunningHub, orientado a fotografia de producto y composicion de imagenes. La informacion publicada no incluye arquitectura detallada, licencia explicita, idiomas ni evaluaciones cuantitativas, por lo que buena parte de las especificaciones quedan como no disponibles.

- Aplicacion de iluminacion coherente a productos u objetos dentro de una escena generada.

## Casos de uso

- Fotografia de producto para comercio electronico: se genera o introduce un producto y el LoRA se encarga de que la iluminacion coincida con la del fondo y de que aparezca una sombra de contacto creible, evitando el aspecto de recorte pegado. Adecuado porque ese es exactamente el efecto declarado por el autor.
- Creacion de creatividades publicitarias: insercion de un envase o dispositivo en escenas de estilo de vida manteniendo coherencia de luz entre el objeto y el entorno, lo que reduce el trabajo de retoque posterior.
- Pipelines por lotes en ComfyUI: al ser un safetensors de 160 MiB, se puede cargar como nodo LoRA en un flujo de ComfyUI y aplicar el mismo tratamiento de luz a cientos de imagenes de catalogo de forma reproducible con la palabra `pengyu`.
- Automatizacion via API de RunningHub: la model card enlaza la API de la plataforma, de modo que el adaptador puede invocarse en un servicio remoto sin gestionar GPU propia, util para equipos que generan material visual bajo demanda.
- Previsualizacion para fotografia y 3D: integracion de renders o modelos de producto en fondos fotograficos con sombra de contacto y luz coherente, para validar composiciones antes del shooting o del render final.
- Generacion de material para marketplaces: normalizacion del aspecto de las imagenes de listado (iluminacion uniforme, sombras consistentes) para que un catalogo mantenga un estilo visual homogeneo.
- Composicion de escenas de interiorismo o decoracion: colocacion de muebles u objetos en estancias generadas, donde la coherencia entre luz ambiental y objeto resulta critica.
- Contenido para redes sociales: produccion rapida de variaciones de una misma imagen de producto cambiando el fondo pero conservando un tratamiento de luz consistente.
