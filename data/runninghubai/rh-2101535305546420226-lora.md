# RunningHubAI/rh-2101535305546420226-lora

## Resumen

`rh-2101535305546420226-lora` es un adaptador LoRA para edición de imágenes (pipeline `image-text-to-image`) publicado por RunningHubAI en Hugging Face. No se trata de un modelo base autónomo, sino de un conjunto de pesos de ajuste fino pensado para cargarse sobre un modelo generativo subyacente; según la model card, está afinado a partir de `krea2`. El artefacto principal es un único fichero `Pastel illustration.safetensors` de 224 MiB, lo que sitúa el repositorio en unos 0,2 GB.

El modelo está orientado a la generación y edición de ilustraciones digitales con un estilo semirrealista de inspiración anime, con estética pastel. La descripción del autor detalla un sujeto concreto (mujer joven de pelo rubio corto y rizado, gafas redondas rosadas, cardigan amarillo claro y vaqueros azules de talle alto), lo que sugiere que el LoRA fue entrenado para reproducir un estilo y una composición determinados más que para cubrir un dominio general.

La relevancia práctica es acotada: se distribuye como complemento para flujos de ComfyUI y para la plataforma RunningHub, sin licencia declarada, sin idiomas declarados y sin métricas publicadas. No hay información sobre el proceso de entrenamiento, el dataset ni evaluaciones cuantitativas.

## Arquitectura y entrenamiento

El artefacto es un adaptador LoRA, es decir, un conjunto de matrices de bajo rango que se inyectan en las capas del modelo base para modificar su comportamiento sin reentrenar todos los pesos. El modelo base declarado es `krea2`, y el pipeline asociado es `image-text-to-image`, lo que implica que el adaptador opera en un flujo de generación condicionada por texto (y potencialmente por una imagen de entrada, dado el uso de "image edit" en la model card). No se especifica sobre qué módulos del transformer se aplican las matrices, ni el rango, ni el alpha, ni la tasa de aprendizaje.

No hay información pública sobre el número de pasos de entrenamiento, el volumen o composición del dataset, el uso de regularización, ni si se emplearon técnicas como captions automáticos o aumentación. Tampoco se documenta ninguna innovación técnica adicional (decodificación especulativa, atención lineal, etc.), lo cual es esperable en un adaptador de este tipo. El tamaño del repositorio (0,2 GB) es coherente con un LoRA de rango moderado sobre un modelo de difusión de escala media.
