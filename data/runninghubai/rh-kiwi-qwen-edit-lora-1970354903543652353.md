# RunningHubAI/rh-kiwi-qwen-edit-lora-1970354903543652353

## Resumen

rh-kiwi-qwen-edit-lora es un adaptador LoRA de edicion de imagen publicado por RunningHubAI en nombre del autor KIWI. No se trata de un modelo base autonomo, sino de un conjunto de pesos de 225 MiB (0,2 GB en el repositorio) que se aplica sobre Qwen-Edit-2509, el modelo de edicion de imagen de la familia Qwen. Su funcion es especializar ese modelo base para transformar el sujeto principal de una imagen en una figura coleccionable a escala 1/7, con acabado realista y una escena de escritorio de coleccionista.

El adaptador se distribuye en formato safetensors y esta pensado para cargarse en ComfyUI o en la plataforma RunningHub, con un pipeline declarado de image-text-to-image. La model card recomienda un peso de LoRA de 1,0 y proporciona una plantilla de prompt detallada, ademas de ajustes de muestreo concretos (Euler, CFG 4, 30 pasos, resolucion con lado largo hasta 1664 px).

La relevancia de esta ficha es acotada: se trata de un LoRA muy especifico, orientado a un unico efecto visual, sin documentacion sobre datos de entrenamiento, licencia o evaluacion. Resulta util para quien quiera reproducir el efecto "personaje a figura" dentro de un flujo ComfyUI, pero no constituye una base general para edicion de imagen.

- Prototipado de merchandising: convertir una ilustracion de personaje en una imagen de figura coleccionable para presentar conceptos a fabricantes o clientes antes de modelar en 3D.

- Automatizacion via API de RunningHub: integrar el LoRA en un pipeline que reciba una imagen y un prompt y devuelva la figura renderizada, sin gestionar infraestructura propia.
- Exploracion de estilos de presentacion: variar el prompt para cambiar el entorno (escritorio, estanteria, vitrina) manteniendo el efecto de figura a escala 1/7.
