# RunningHubAI/rh-2028078768446771202-lora

## Resumen

`rh-2028078768446771202-lora` es un adaptador LoRA de texto a imagen publicado por RunningHubAI en nombre del usuario «OSM开源电影» de la plataforma RunningHub. No se trata de un modelo de lenguaje ni de un modelo fundacional: es un ajuste fino ligero (280 MiB en `safetensors`) pensado para inyectar un estilo visual concreto, descrito por el autor como «科幻电影风格» (estilo de cine de ciencia ficción), sobre un modelo base de generación de imágenes.

El adaptador se entrena y distribuye a través del ecosistema de RunningHub, una plataforma china de flujos de trabajo de generación visual compatible con ComfyUI. Según la model card, el ajuste parte de **Qwen-Image-2512**, un modelo de difusión de la familia Qwen-Image, y se activa mediante la palabra disparadora «科幻电影». El repositorio contiene únicamente los pesos del LoRA, no el modelo base.

La relevancia de esta ficha es limitada en el ámbito de la IA open source para desarrolladores: se trata de un artefacto de estilo de nicho, sin documentación técnica sobre datos de entrenamiento, hiperparámetros, licencia explícita ni evaluaciones. Resulta útil, eso sí, como ejemplo del patrón de publicación de LoRAs en plataformas de generación de imágenes y para quienes quieran reproducir el estilo en ComfyUI o vía API de RunningHub.

## Arquitectura y entrenamiento

El artefacto es un LoRA, es decir, un conjunto de matrices de bajo rango que se suman a determinadas capas del modelo base para modificar su comportamiento sin reentrenar todos los pesos. El modelo base declarado es Qwen-Image-2512, un modelo de difusión de la familia Qwen-Image orientado a generación de imágenes a partir de texto. El nombre del fichero (`qwen-科幻电影_resized_from_64_to_16_fp16_00001_.safetensors`) sugiere un reescalado de resolución de 64 a 16 y una conversión a `fp16`, aunque no se documenta qué significa exactamente ese reescalado ni a qué componente afecta.

No se publica información sobre el conjunto de datos de entrenamiento (número de imágenes, procedencia, resolución, captioning), los hiperparámetros (rango, alpha, tasa de aprendizaje, pasos), ni si hubo regularización o validación. Tampoco se indica si el adaptador afecta solo al UNet/diT o también a los codificadores de texto. La única indicación funcional es la palabra disparadora «科幻电影», que debe incluirse en el prompt para activar el estilo.
