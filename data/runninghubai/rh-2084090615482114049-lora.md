# RunningHubAI/rh-2084090615482114049-lora

## Resumen

rh-2084090615482114049-lora es un adaptador LoRA para edición de imágenes (pipeline `image-text-to-image`) publicado por RunningHubAI en Hugging Face. Se trata de un peso de 224 MiB en formato safetensors, afinado a partir del modelo base krea2, y su función es aplicar un estilo visual concreto (estética retro japonesa de era Showa, según el nombre del archivo `Showa retro style.safetensors`). El adaptador se carga sobre ComfyUI, RunningHub o directamente en Hugging Face, y se activa mediante la palabra disparadora `digital illustration` con un peso recomendado de 0,9.

El modelo no es un modelo fundacional autónomo, sino un complemento de bajo rango que modifica el comportamiento de un modelo generativo de imágenes ya existente. Por tanto, sus capacidades, contexto y rendimiento dependen del modelo base sobre el que se aplique, no del LoRA en sí. El repositorio es de tamaño reducido (0,2 GB) y no incluye información sobre el dataset de entrenamiento, el número de pasos, el rango del LoRA ni la licencia aplicable.

La relevancia de esta ficha es limitada desde el punto de vista técnico: se publica como un artefacto de estilo dentro del ecosistema RunningHub, con escasa documentación y sin métricas publicadas. Resulta útil para quien quiera reproducir el estilo en un flujo ComfyUI, pero no constituye una base para evaluación comparativa de modelos.
