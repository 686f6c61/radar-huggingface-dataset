# RunningHubAI/rh-mj-lora-2101990068243230721

## Resumen

rh-mj-lora es un adaptador LoRA de edición de imágenes publicado por RunningHubAI en Hugging Face. Se distribuye como un único archivo de pesos (`MJ插画风格.safetensors`, 224 MiB) y está etiquetado con el pipeline `image-text-to-image`, lo que indica que se usa junto a un modelo base de difusión para transformar una imagen de entrada guiada por una instrucción textual. El autor del LoRA es el usuario de RunningHub identificado como @洛川MLKBC, y la model card indica que se ha afinado a partir de "krea2".

El modelo no es un modelo de lenguaje: no procesa texto de forma generativa ni expone parámetros, contexto o capacidades lingüísticas. Su función es aplicar un estilo visual concreto (la model card lo denomina "MJ插画风格", es decir, estilo ilustración MJ) sobre imágenes en flujos de trabajo de ComfyUI o en la plataforma RunningHub. La descripción incluida en la model card es un ejemplo de prompt que describe una escena de motel retro con una mujer en un sofá de mediados de siglo, lo que sugiere el tipo de resultado estético que busca el adaptador.

La relevancia de esta ficha es limitada desde el punto de vista de la evaluación técnica: el repositorio no incluye información sobre datos de entrenamiento, hiperparámetros, licencia explícita ni benchmarks. Es un artefacto de estilo orientado a un ecosistema concreto (ComfyUI/RunningHub) y su interés principal es práctico para quien quiera reproducir ese estilo en un pipeline de edición de imagen.
