## Resumen

No se trata de un modelo de lenguaje, sino de un conjunto de pesos de ajuste fino (fine-tuning) destinado a modificar el comportamiento de un modelo base de generación de vídeo: la model card indica explícitamente que se ha entrenado a partir de WAN2.2.
