# RunningHubAI/rh-2023910539876900866-lora

## Resumen

rh-2023910539876900866-lora es un adaptador LoRA de generacion de imagenes (text-to-image) publicado por RunningHubAI bajo el identificador interno 2023910539876900866. Se trata de un ajuste fino derivado del modelo base Flux2-Klein-9B, orientado a un estilo visual muy concreto: retratos de perfil femeninos con estetica "guochao" (国潮, corriente de diseno chino contemporaneo que fusiona motivos tradicionales con lenguaje grafico moderno). El autor original listado en la model card es el usuario RunningHub @Li鱼.

El repositorio contiene un unico fichero de pesos en formato safetensors de 83 MiB, lo que confirma que no es un modelo completo sino un adaptador de bajo rango pensado para cargarse sobre el modelo base en ComfyUI, RunningHub o Hugging Face. El unico disparador documentado es la palabra `guochaoface`, que debe incluirse en el prompt para activar el estilo entrenado.

La relevancia de esta ficha es limitada fuera de su nicho: no hay informacion publica sobre datos de entrenamiento, hiperparametros, licencia o evaluacion cuantitativa, y el modelo acumula cero descargas y cero likes en el momento de la consulta. Es util, por tanto, como referencia de un LoRA de estilo muy especializado dentro del ecosistema ComfyUI, no como modelo de proposito general.

## Arquitectura y entrenamiento

El artefacto es un adaptador LoRA, es decir, un conjunto de matrices de bajo rango que se inyectan en las capas del modelo base Flux2-Klein-9B para modificar su comportamiento generativo sin reentrenar los pesos completos. El modelo base pertenece a la familia Flux2, un transformer de difusion para generacion de imagenes; la variante Klein-9B indica un tamano de aproximadamente 9.000 millones de parametros. El adaptador ocupa 83 MiB, coherente con un rango bajo y un conjunto de capas objetivo acotado.

No se dispone de informacion sobre el numero de imagenes de entrenamiento, la composicion del dataset, el numero de pasos, la tasa de aprendizaje ni si se aplicaron tecnicas de regularizacion o captions automaticos. La model card solo indica el modelo de partida, la plataforma de entrenamiento (RunningHub) y la palabra disparadora `guochaoface`. No hay evidencia de RLHF, DPO ni de innovaciones tecnicas adicionales; se trata de un ajuste de estilo convencional dentro del flujo de trabajo de ComfyUI.
