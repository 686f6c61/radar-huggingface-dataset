# RunningHubAI/rh-krea2-lora-2091505707577716738

## Resumen

rh-krea2-lora es un adaptador LoRA de edicion de imagen publicado por RunningHubAI en Hugging Face. Se distribuye como un unico fichero de pesos (`Krea2电影艺术人像写真.safetensors`, 224 MiB) y esta afinado a partir del modelo base `krea2`, segun indica la model card. El pipeline declarado es `image-text-to-image`, es decir, generacion y edicion de imagenes condicionada por texto e imagen de entrada. El repositorio tiene 0,2 GB de tamano total, 0 descargas y 0 likes en el momento de la consulta.

El proposito del adaptador, deducible del nombre del fichero de pesos (en chino, "retrato fotografico artistico cinematografico Krea2"), es desplazar el estilo del modelo base hacia retratos fotograficos con acabado cinematografico. No es un modelo fundacional autonomo: requiere cargarse junto con el modelo base `krea2` en un entorno compatible, principalmente ComfyUI, plataforma para la que esta etiquetado.

La relevancia de esta ficha es limitada desde el punto de vista de la investigacion: se trata de un artefacto de estilo de autor, sin model card tecnica detallada, sin licencia declarada y sin datos de entrenamiento ni evaluacion publicados. Resulta util, no obstante, como ejemplo del flujo de publicacion de LoRA de estilo en el ecosistema ComfyUI y como referencia para quien necesite evaluar rapidamente si un adaptador de este tipo encaja en un pipeline de generacion de retratos.

- Prototipado de personajes para narrativa visual: combinado con el modelo base, sirve para fijar una estetica de retrato antes de invertir en un entrenamiento de mayor alcance.
