# RunningHubAI/rh-krea2-lora-2075968320674754561

## Resumen

rh-krea2-lora es un adaptador LoRA de edicion de imagen publicado por RunningHubAI (cuenta institucional de la plataforma RunningHub) en nombre del autor identificado como @T8star. No se trata de un modelo de lenguaje ni de un modelo base autonomo, sino de un peso adicional que se carga sobre un modelo generativo de imagenes al que la model card denomina "krea2", del que este LoRA es un finetune. El pipeline declarado es image-text-to-image, es decir, generacion y edicion de imagenes condicionada por texto y potencialmente por una imagen de entrada.

El unico artefacto del repositorio es el archivo `krea2胸部调节器.safetensors`, de aproximadamente 20 MiB, descrito en la model card como un "chest adjuster" (regulador de pecho). Esto situa al adaptador en la categoria de LoRA de edicion fina orientada a modificar un atributo anatomico concreto dentro del flujo de generacion, no a cubrir capacidades generales.

La relevancia del modelo es limitada y muy nicho: esta pensado para ejecutarse en ComfyUI, RunningHub o Hugging Face sobre el modelo base krea2, y en el momento de la publicacion el repositorio registraba 0 descargas y 0 likes. No hay informacion publica sobre el dataset de entrenamiento, la licencia aplicable ni resultados de evaluacion.
