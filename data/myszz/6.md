# Myszz/6

## Resumen

Myszz/6 es un adaptador LoRA publicado en Hugging Face por el usuario Myszz. No se trata de un modelo de lenguaje autocontenido, sino de un conjunto de pesos de ajuste fino (adapter) que se aplica sobre el modelo base Wan-AI/Wan2.2-TI2V-5B-Diffusers, un modelo de difusion de la familia Wan 2.2 orientado a generacion de video a partir de texto e imagen (text-to-video e image-to-video). El repositorio tiene un tamano de 0,3 GB, coherente con un adaptador LoRA de rango bajo y no con un checkpoint completo.

La model card es una plantilla sin completar: todos los campos (autor, tipo de modelo, licencia, datos de entrenamiento, evaluacion) figuran como "[More Information Needed]". Por tanto, la informacion tecnica disponible se limita a los metadatos del repositorio: libreria PEFT 0.19.1, formato safetensors, tag lora y modelo base declarado. El repositorio registra 0 descargas y 0 likes en el momento de la consulta, lo que sugiere un artefacto experimental o de uso privado sin validacion comunitaria.

Su relevancia es limitada y circunstancial: sirve como ejemplo de adaptador PEFT sobre un modelo de difusion de video, pero no hay evidencia publica de su comportamiento, del dataset de ajuste ni de las condiciones de uso. Cualquier evaluacion practica exige cargarlo junto al modelo base Wan2.2-TI2V-5B-Diffusers y reproducir el pipeline de difusion correspondiente.

## Arquitectura y entrenamiento

El artefacto es un adaptador LoRA, tal como indican los tags `peft`, `lora` y `safetensors`, junto con la dependencia declarada de PEFT 0.19.1. La arquitectura subyacente corresponde al modelo base Wan-AI/Wan2.2-TI2V-5B-Diffusers, un modelo de difusion para generacion de video condicionada por texto e imagen. El adaptador modifica un subconjunto de matrices del modelo base mediante descomposiciones de rango bajo, sin alterar el resto de pesos.

No hay informacion sobre el dataset de entrenamiento, el numero de pasos, el rango del LoRA, el alpha, la tasa de aprendizaje ni la precision utilizada (fp16, bf16, fp32). Tampoco se documenta si hubo ajuste con RLHF, DPO o cualquier otra etapa de alineamiento, algo poco habitual en adaptadores de difusion. La unica referencia bibliografica presente en los metadatos es el paper arXiv:1910.09700 (Lacoste et al., calculadora de impacto medioambiental), que aparece como tag generico de la plantilla y no como publicacion del modelo.

## Capacidades

- Generacion de video condicionada por texto (text-to-video) a traves del modelo base Wan2.2-TI2V-5B, segun la nomenclatura TI2V del checkpoint.
- Generacion de video condicionada por imagen (image-to-video), tambien inferida del identificador TI2V del modelo base.
- Ajuste fino especifico mediante LoRA: el adaptador puede modular el estilo, el dominio o el comportamiento del modelo base, aunque no se documenta cual es esa modificacion.
- Compatibilidad con el ecosistema PEFT: carga mediante `PeftModel` sobre el pipeline de difusion del modelo base.
- No se documentan capacidades de tool calling, razonamiento multi-paso, agentes, vision analitica, audio ni modo thinking, ya que no es un modelo de lenguaje.
