# jlsrls/smoke-1788440619

## Resumen

`jlsrls/smoke-1788440619` es un modelo de lenguaje fino-ajustado (fine-tuned) a partir de `unsloth/Llama-3.2-1B-Instruct`, desarrollado por el usuario `jlsrls`. Según la información disponible, el modelo fue entrenado mediante aprendizaje supervisado (SFT) utilizando la librería TRL de HuggingFace, junto con Transformers y PyTorch. Se trata de un experimento de afinamiento sobre una base de 1.000 millones de parámetros, orientado a instrucciones.

El modelo se publicó el 3 de septiembre de 2026 y no presenta descargas ni valoraciones en el momento de la consulta. La información pública es escasa: no se especifica licencia, idiomas soportados, dataset de entrenamiento ni métricas de evaluación. La model card incluye únicamente un ejemplo de uso con `pipeline` de Transformers y los detalles del framework de entrenamiento. Su relevancia actual reside en ser un ejemplo de fine-tuning accesible sobre Llama 3.2 1B, útil para quienes exploran flujos de SFT con TRL y Unsloth.

## Arquitectura y entrenamiento

El modelo se basa en la arquitectura Llama 3.2 1B Instruct, un transformer decoder-only con atención causal estándar, normalización RMSNorm, y activación SwiGLU. Al ser un fine-tuning, hereda la estructura del modelo base: 16 capas, 32 cabezas de atención, dimensión oculta de 2048 y embedding de 2048. El modelo base de Unsloth está optimizado para fine-tuning eficiente en memoria.

El entrenamiento se realizó con SFT (Supervised Fine-Tuning) mediante TRL 0.24.0, con Transformers 5.5.0 y PyTorch 2.11.0. No se especifica el dataset utilizado, el número de tokens de entrenamiento, ni si se aplicaron técnicas adicionales como RLHF o DPO. El repositorio de Weights & Biases vinculado pertenece a un proyecto de "clarifying-em" de la Portland State University, lo que sugiere un posible contexto académico, aunque no se detalla la composición de los datos. No hay evidencia de innovaciones técnicas adicionales más allá del propio fine-tuning.
