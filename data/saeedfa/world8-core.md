# Saeedfa/world8-core

## Resumen

World 8 Core es un repositorio publicado en Hugging Face por el autor Saeedfa que, según su model card, no contiene un modelo de inteligencia artificial entrenado. Se presenta como una "superficie de presentación/mirror público de artefactos seguros del núcleo de World 8", un proyecto de arquitectura digital gobernada que aborda identidad persistente, cerebros de IA reemplazables, autoridad explícita y desarrollo acotado por evidencia. El estado declarado es "development pre-release / non-production" y se indica explícitamente que no se reclama ningún modelo fundacional entrenado.

El proyecto World 8 se describe como una arquitectura multi-sociedad con gobernanza, pero no se proporcionan especificaciones técnicas de ningún modelo de lenguaje, visión u otro tipo. La entrada en Hugging Face tiene cero descargas y cero likes, y no se dispone de pipeline, licencia ni idiomas declarados. La información disponible se limita a enlaces canónicos a GitHub y Zenodo, así como a un commit congelado y referencias DOI. Por tanto, esta ficha documenta un artefacto de software o especificación, no un modelo de IA utilizable para inferencia.
