# algorithm-intelligence-llc/eval-20261123-205523-newt

## Resumen

El modelo `eval-20261123-205523-newt` es un ajuste fino (fine-tune) del modelo `moonshotai/Moonlight-16B-A3B`, publicado por el usuario `algorithm-intelligence-llc` en Hugging Face. Se trata de un modelo de generación de texto con arquitectura DeepSeek-V3 (MoE, Mixture of Experts), derivado del trabajo de Moonshot AI, y entrenado sobre el dataset `algorithm-intelligence-llc/pubmedqa-official-split`, lo que sugiere una especialización en el dominio biomédico y de preguntas-respuestas clínicas.

El modelo cuenta con 15.960.108.544 parámetros totales (aproximadamente 16 mil millones), lo que lo sitúa en la categoría de modelos medianos con activación dispersa. El identificador del repositorio (`eval-...`) y la ausencia de documentación, benchmarks o tarjeta de modelo detallada indican que se trata de un artefacto de evaluación interno más que de un modelo listo para producción.

Su relevancia actual es limitada: se publica bajo licencia MIT, pero el acceso está restringido (gated) y no incluye información sobre idiomas, cuantizaciones ni datos de entrenamiento. Para desarrolladores e investigadores, este modelo resulta interesante como ejemplo de fine-tuning de Moonlight-16B-A3B sobre datos de PubMedQA, pero no como un modelo listo para despliegue sin una evaluación adicional.

## Arquitectura y entrenamiento

El modelo hereda la arquitectura `deepseek_v3` del modelo base `moonshotai/Moonlight-16B-A3B`. Esta arquitectura corresponde a un transformer con mezcla de expertos (MoE), donde solo una fracción de los parámetros se activa por token, lo que permite un equilibrio entre capacidad y coste computacional. El número total de parámetros es de aproximadamente 16 mil millones, aunque no se dispone del dato de parámetros activos en la información proporcionada.

El fine-tuning se ha realizado sobre el dataset `algorithm-intelligence-llc/pubmedqa-official-split`, una partición oficial del corpus PubMedQA, orientado a preguntas y respuestas biomédicas. No se dispone de información sobre el número de tokens de entrenamiento, la composición exacta del dataset, la existencia de RLHF/DPO, ni sobre innovaciones técnicas adicionales (decodificación especulativa, atención lineal, etc.). El identificador del repositorio sugiere que se trata de un experimento de evaluación más que de un modelo documentado para producción.
