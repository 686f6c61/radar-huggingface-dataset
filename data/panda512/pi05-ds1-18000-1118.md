# Panda512/pi05-ds1-18000-1118

## Resumen

Panda512/pi05-ds1-18000-1118 es un adaptador LoRA (PEFT) publicado en Hugging Face por el usuario Panda512. No se trata de un modelo base completo, sino de un conjunto de pesos de adaptacion que se aplican sobre el modelo referenciado en la etiqueta `base_model:adapter`, que apunta a una instantanea local del modelo `lerobot/pi05_base`. El repositorio ocupa 1,9 GB y contiene pesos en formato safetensors, con la libreria PEFT 0.21.2 declarada en la model card.

La model card es la plantilla generica de Hugging Face sin completar: no aporta informacion sobre el desarrollador, el tipo de modelo, los idiomas, la licencia, los datos de entrenamiento ni los resultados de evaluacion. Toda la informacion disponible se reduce a los metadatos del repositorio. El nombre del identificador (`pi05-ds1-18000-1118`) sugiere, por convencion, un fine-tuning sobre el modelo pi05 con un dataset o configuracion "ds1", 18.000 pasos o muestras y una marca temporal 1118, pero esto es una inferencia a partir del nombre y no un dato confirmado por el autor.

Por tanto, esta ficha describe un artefacto de adaptacion de bajo nivel de trazabilidad. Es relevante unicamente para quien ya trabaje con el ecosistema LeRobot/pi05 y quiera reutilizar o inspeccionar el adaptador; no es un modelo autonomo listo para produccion ni dispone de documentacion que permita evaluar su calidad.

## Arquitectura y entrenamiento

El repositorio es un adaptador PEFT de tipo LoRA, segun las etiquetas `peft` y `lora`. Se aplica sobre el modelo base `lerobot/pi05_base`, referenciado mediante una ruta local del sistema de archivos del autor (`/projects/lerobot/.tmp/hf/hub/models--lerobot--pi05_base/snapshots/...`), lo que indica que el entrenamiento se realizo en un entorno con LeRobot, el framework de robotica de Hugging Face. No hay informacion publica sobre el numero de tokens, la composicion del dataset, el regimen de entrenamiento (precision, hiperparametros, rango de LoRA) ni si se aplico RLHF o DPO.
