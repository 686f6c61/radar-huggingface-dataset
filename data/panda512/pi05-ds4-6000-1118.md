# Panda512/pi05-ds4-6000-1118

## Resumen

Panda512/pi05-ds4-6000-1118 es un adaptador LoRA publicado en Hugging Face por el usuario Panda512, construido sobre el modelo base `lerobot/pi05_base` (referenciado en los metadatos como una ruta local de snapshot del Hub de LeRobot). El repositorio no es un modelo completo, sino un conjunto de pesos de adaptación PEFT (version 0.21.2) en formato safetensors, con un tamano de repositorio de 1.9 GB. La model card es la plantilla por defecto de Hugging Face sin rellenar, por lo que el autor no documenta proposito, datos de entrenamiento ni evaluacion.

El nombre del repositorio sugiere un fine-tuning asociado a LeRobot (el stack de robotica open source de Hugging Face) y a un dataset o configuracion identificada como "ds4" con 6000 pasos o muestras y una marca temporal 1118, pero esta interpretacion no esta confirmada por ninguna fuente oficial. El tag `base_model:adapter` apunta a un snapshot de `lerobot/pi05_base`, lo que situa el modelo en la familia pi0/pi0.5 de politicas vision-language-action (VLA) para control robotico, no en el espacio de los LLM de texto.

La relevancia actual es limitada y muy especifica: se trata de un artefacto de experimentacion sin documentacion, sin descargas ni likes en el momento de la consulta, y con licencia no declarada. Resulta util unicamente como referencia para quien quiera inspeccionar un adaptador LoRA sobre pi05_base, no como modelo listo para produccion.
